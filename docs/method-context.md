# 方法笔记与默认研究建议（V1-04A）

本项修复研究上下文的来源、方法状态和默认建议，不声称方法已科学验证，也不代表完整提示词预算或通用执行闭环已经完成。

## 方法笔记不是验证结论

`results/_methods/*.yaml` 是作者提供的候选笔记。写了论文路径、源码路径、状态或 `proven_score`，都不能使它成为已验证观察。有效候选仍可帮助探索；不要求先证明一个新想法才允许提出它。零分值保留为作者声称的数值，不因真假值判断丢失。

读取器绑定实际读取文件的 canonical 路径、字节 SHA256 和结果目录范围；这些生成字段覆盖文件内同名声明。作者的 `source` 字段仅是声明的出处，不是框架已读取该论文/代码的证据。哈希说明本次读到了哪些字节，不证明内容真实。

退役、停用、撤回及既有机械策略阻塞的方法，不再作为可执行配方进入研究提示词。上下文保留有限状态、原因、再启用条件和来源摘要；这些条件仍是笔记，不授予重新启用权限。直接调用 renderer 同样不能通过退役状态取回配方。

## 当前读取与有限成本

方法读取不再使用目录最大 mtime 缓存。修改、删除或同大小同 mtime 替换在下一次读取时重新核实，不返回旧缓存兜底。文件枚举、读取字节和 YAML 解析均有上限；重定向、非普通文件、共享文件身份、YAML alias/重复键及同名冲突保守处理。坏文件不自动吞掉其他已经成功读取的独立方法。

本版上限：128 个目录项、每个 YAML 64 KiB、一次读取预约合计 1 MiB（含检测增长的额外字节）、4096 个 YAML 事件、24 层嵌套。方法笔记使用字符串映射键及有限 JSON 形状值；其他 YAML 任务配置不受本读取器限制。方法展示片段至多 32768 字符，包含省略标记；这不是整个提示词的 UTF-8 字节预算。

诊断属于来源可用性说明，不是方法失败或科学负结果。该方法专用读取路径不改变既有 validators、portfolios 的加载和激活语义。逐文件读取不等于整个目录原子快照，也不抵御能任意改写项目控制目录的恶意作者。

读取诊断区分确实不存在、已读取、部分省略及不可用。关闭目录描述符报错时不重试关闭旧编号，以免关闭被其他操作复用的描述符；本项不提供执行任务恢复或自动接管权限。

## 默认建议与项目政策

默认提示词不再根据家族占比、短期榜单停滞或重复提案直接宣布局部最优/方向耗尽，不要求家族配额或模型/数据两路交替，也不承诺每项提案会自动训练。明确的项目政策、原有 JSON 提案格式及机械校验仍保留。

这是对默认建议的修正，不是新策略运行器。旧提案字段、家族枚举及示例仍保留兼容，不应宣传为所有领域任务 schema 已完成通用化。移除的历史 70% 家族分支在本轮基线因已不存在的 Core import 而不可达，因此没有把它算作现场行为缺陷。
