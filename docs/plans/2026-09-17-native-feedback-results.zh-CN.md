## 对此前实验的修正

此前 CPU 收集器确实独立评价了模型候选，但 Pro 的报告分页只读取旧式 `metrics.json`。
原生 CPU 评价被显示为 `local_metrics_missing`，记忆来源绑定也被拒绝。因此此前的候选
质量和实际费用仍成立，但不能视为模型根据评价反馈进行迭代学习的对照。此前报告中
“首次消费有效／最优证据”的时间是收集器的时间，不是模型读到证据的时间。
[此前结果](2026-09-16-real-memory-results.zh-CN.md)已加明确修正，原件和失败均保留。

## 本轮改变

- Pro 的原生 CPU 证据适配器复用 Core 的当前执行记录、提交回执和产物内容校验。
  页面保留评价器的有效、无效和未知状态、实际数值、比较范围及输入／输出来源。
  无效观察可以作为反例引用；它不会得到虚构分数，也不进入旧式成绩排名。
- 记忆绑定覆盖候选、评价产物和提交回执；来源内容变化、文件替换或执行版本变化后，
  旧引用失效。来源有效只说明出处有效，不保证模型写出的自然语言结论正确。
- 提示词明确先选择读取证据、更新记忆或提出候选。去掉格式示例中的 Markdown 包装，
  并说明控制请求与最终提案分别响应。真实诊断中，仅调整提示词仍未消除格式失败。
- 完整单个 JSON 代码块经过解包后执行相同严格 JSON 和写入校验；附加文字、混合提案、
  重复键、非有限数、嵌套控制仍拒绝。来源、修订号、写入次数和调用预算校验继续生效。

## 诊断与对照范围

诊断从实际评价过的一个有效排程及一个容量冲突排程开始，明确要求在提供记忆协议时
先保存一个带来源的反例，再提出改进。有效种子已包含最优解，因此这些诊断只检验机制，
不计作研究创新或质量提升。原始提示词、响应、用量、候选与评价都保留。

前五次诊断依次覆盖：修复前 Haiku、接通反馈后的 Haiku、同条件 Sonnet 5、提示词选择
顺序调整、移除代码块示例。Haiku 看到了真实反馈，并开始请求记忆写入，但完整代码块
仍被旧分类器拒绝。Sonnet 两轮均输出截断，没有可用响应；费用约 0.215006 美元，不能
当作零成本跳过。Haiku 一条未写入的说明把实际发生于 tick 4–5 的重叠误写成 tick 3，
这也说明引用资格不能替代内容核验。

第六次诊断接受完整包装，两个研究轮次共用 200000 token 的进程额度。此前诊断共用
100000；新额度仍在原来两轮的 2 美元保守预留内。这个差异明确保留，不把前后诊断
解释为等预算研究收益。后续四对对照沿用原先每研究进程 100000 的额度。

四对实验沿用同一 Haiku、同样两个任务、重复与顺序、每项目四轮、每轮两个候选，
A 关闭记忆、B 开启可选记忆；两边均有相同的原生反馈接口。记忆仍从空文档开始。
最终质量独立复验，固定四轮的全部调用、格式失败、重复提案和时间都计入。
这些任务很小，不能替代长历史或跨领域、独立盲测的研究收益验收。

## 真实记忆诊断结果

第六次 Haiku 诊断实际进行了 4 次 API 调用。真实提示词依次显示记忆版本
`1 → 2 → 2 → 3`：第一次写入后重新读取成功，第二个研究轮次也看到版本 2 的笔记，
引用来源均为 `current`。这证明实际模型、来源绑定、持久化和跨轮读取已连通。

但研究行为没有随之改善：模型继续请求内容相同的笔记，最终保存了两条语义重复的
容量反例，没有产生新提案。两轮分别止于缺少 `refresh` 字段的无效控制请求，以及
单轮写入次数上限。记录中的核心容量冲突符合独立评价；`claim_verified` 仍为 false，
自然语言说明没有被系统自动认证为正确。

完整诊断为 **107.439 秒**，其中模型调用合计 **18.781 秒**，其余约 **88.658 秒**包含
CPU 种子生成／评价、上下文与来源校验、记忆提交等本地工作。未做分项性能剖析，不能
把这部分全部归因于某一个函数。API 已知费用为 **0.047042 美元**。因此这次结果是
“记忆机制实际可用，同时暴露重复记录和额外开销”，不是“研究提速”。

## 判断与下一项研究问题

能力链路有明确进展：真实 CPU 评价终于进入模型，实际模型写入并跨轮读到了带来源的
反例。但本轮仍未证明持久记忆提高研究质量或降低单位有效结论成本。应保留可选状态，
不因“能写入”就强制每轮写笔记；强制诊断已暴露重复记录和明显本地开销。

下一项研究问题是：在确实需要跨轮保留失败证据的更难任务中，合理选择何时写／读记忆，
能否在同等预算下减少无效候选并提高最终质量。写入额度用完后仍展示写入说明、反复记录
同一事实，以及高额校验开销均已记录；后续变更必须针对实验中的损耗再验证，不能继续
以通用工程规模替代研究收益。[原交接整体目标](2026-09-16-original-scope-status.zh-CN.md)
仍未完成，尤其是长历史、跨领域研究与生产上线验收。
