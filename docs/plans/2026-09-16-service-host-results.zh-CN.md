# 常驻服务宿主与独立项目管理：验证结果

本片为显式项目接通常驻服务宿主。实际 CPU 控制器及其后继由同一宿主持有，
watchdog 通过认证通道请求交接；客户端退出后宿主和后继继续运行。
这完成了一段服务集成，**没有完成旧服务迁移、冷恢复或生产上线**。

基线 Core `fefa4165b79838e230a1aaf1ae4eb71c6bd20ef8`、Pro
`26ec4cf2150837b483c941a6cf6c4639f1bd24d9`。Pro 产品源码未修改；Core 六个既有源码
文件修改、两个源码模块和两个测试文件新增，所有既有测试保持原件。

## 行为变化

- `--service-config` 为 install／status／audit／logs／uninstall 选择同一项目。
  main service、watchdog service、timer 的名字按显式配置路径区分，文件碰撞不覆盖。
- 常驻 host 创建实际原 CLI 子进程并保留 Popen／pidfd；首次启动前保存意图，
  子进程加载配置后须经宿主复核才可进入普通注册。旧登记不因此获得接管权。
- watchdog 仅向该宿主请求交接。后继仍走原停止、ACK、实际退出、一次性授权和
  PREPARED／COMMIT／STARTED 协议；原预算和历史保留。
- 最后的启动回执丢失时保留原请求，下一次 watchdog 核对同一请求；其他请求不能
  清掉未知状态再启动。停止信号关闭进一步准入，已创建子进程仍被跟踪。
- systemd 路径检查三个有效 unit 的身份、命令、环境和 timer 目标，拒绝额外
  生命周期命令；宿主检查自身 MainPID／cgroup。卸载在请求停止前后重新核验。
  安装提示中的后续命令带同一配置路径。

## 产品证据

最终定向运行中的十个产品用例涵盖十一个独立作用域，其中两个项目同时运行。
四次实际 CPU 动作保留真实 CLI、数据库、worker 产物、进程树关闭回执及结算：

1. 旧 worker 和后代退出后才创建后继；后继完成另一项任务。重放同一请求不增加子进程。
2. 丢失 STARTED 回复后，新请求被拒绝，下一次 watchdog 恢复原请求，仍只有一个后继。
3. 配置／源码输入变化、错误源控制器以及首次启动时的输入变化被拒绝。
4. 在初始／后继 GO 前停止宿主，不进入新的控制器初始化或消费交接授权。
5. 项目 A 交接并停止时，项目 B 的宿主、控制器和 worker 仍存活，预算仍为 BOUND；
   B 随后单独停止并结算。无宿主时，植入无关进程的 PID 不会使 watchdog 发送信号或启动。

出生观察通道认证的是本夹具宿主的真实子进程。产品使用 `method: process`，
不接触现有服务、实际管理器、真实许可、模型或 GPU。管理命令和有效 unit 属性使用
隔离替身；不能据此声称实际 systemd cgroup 和部署验证通过。

独立 stdlib 检查器以只读方式核对出生记录、注册、ACK、effect、交接和预算哈希。
它支持静态记录一致性；瞬时存活／退出顺序由产品测试支持。机械核验不是另一位审阅者，
也不把测试次数转成科研产出。

## 保留的失败

首次缺模块失败用于记录尚无功能。targeted-v1 将宿主状态放在 results 内，触发既有
旧作用域拒绝；改为显式服务配置旁的独立目录，没有放松原守卫。v2 的新夹具使用了
非法 idea 标题，修正为原格式。v4 的旧 status mock 要求无参调用，保留兼容调用方式。

真实反例包括：子进程出生时改写输入仍执行动作；宿主在首次 GO 前收到停止却仍初始化；
有效 watchdog／timer 路由及额外停止命令被接受，卸载也未在停止前后拒绝漂移。
对应失败原件和修正版均保留。后者九个审计反例和两个卸载反例只操作隔离替身。

最终归档检查器 v1 误把 tar 的内部硬链接编码当作普通文件类型错误，退出 1。
四份旧测试归档各有一个同 inode 的硬链接；v2 核对内部目标、原 inode、载荷与哈希后通过，
归档和产品输入均未改写。两版检查器及原失败运行保留，不记作产品或研究实验失败。

## 仍需完成

旧的未注册 watchdog 原始 PID 路径仍存在，旧 matching-route 反例不能据此宣布已解决。
自然策略结束后的服务管理、宿主已退出后的卸载、冷恢复、迁移、状态备份与回滚仍开放。
持续拒绝未知状态不等于完成所需的正向恢复支持。

真实 systemd、特殊路径的有效属性显示、实际部署与 GPU 行为没有验收。逐次核验不提供
同 UID 任意恶意并发改写的原子隔离。停止后不得通过删除宿主或控制器登记来强制重启。

本片没有新增研究质量或提速对照。当前研究收益判断见[研究进展评估](2026-09-16-research-progress-assessment.zh-CN.md)。
原 P1／P2／P3 目标仍在推进，不能将本片闭合当作整个目标完成。
