# 自适应研究：找到一个有效组合，完整效率仍须提高

## 结论与决定

**真实反馈在六组比较中的一组产生了额外质量收益；其余五组持平，尚未证明普遍研究提效。**
在同样十八次常规初始抽样后，追加八次随机训练 R、一次模型规划八配置 P、两轮反馈各四配置 F。
F 在 airfoil-0 将留出均方误差从 **5.479 降至 4.597，改善 16.1%**；获胜配置来自收到第一批真实反馈后的第二轮。
P 和 R 在六组中都没有超过各自初始选择。所有结果经实际训练及逐行预测复算，没有采用模型自报成绩。

这比“生成合法建议”多了一项研究能力证据：模型能从实验反馈提出一个确认有效的新组合。
范围仍是熟悉公开数据上的有界调参，两次划分不能证明跨任务稳定收益或新科学发现。
P／F 同时改变批大小和模型决定次数；观察到的差异不能单独归因于反馈内容。

本轮作出四个决定：

1. **保留廉价搜索作为实质参照。** 它每项目约一分钟；在没有质量改善的五组，继续模型研究只增加成本。
2. **保留按需自适应反馈，不固定升级为两轮默认。** 一次批量更便宜，但错过本次唯一收益；需要判断哪些未解决问题值得再实验。
3. **只修复实际的信息丢失。** 显式要求保留的证据先分配显示容量，减少读到结果又被新页挤掉的问题；没有新摘要系统或全局默认记忆。
4. **下一步检查实验选择质量。** 在新任务验证能否保住真正最佳对照、避开已经产生相同预测的实验，并据此决定是否追加一轮。继续记录等质量时间和全部失败；不在本划分继续调提示后称作泛化。

## 两个不调用模型的事后诊断

### 收益来自组合，不能归因于单一参数

airfoil-0 的获胜 HistGradientBoosting 同时将学习率从 0.1 改为 0.22、最小叶样本数从 20 改为 5；固定 15 叶、L2=1、160 次迭代、种子 1729。
模型把多因素共同变化描述为沿更大学习率／更松叶限制的单调改善；这些配置没有形成单因素序列，不能据此分离各因素的方向。
我们在原始选择完成后冻结 2×2 对照，复用原来的四份测量，只补四次实际训练，活动时间约 12.8 秒。

| 学习率 | 最小叶样本数 | 开发 MSE | 留出 MSE |
| ---: | ---: | ---: | ---: |
| 0.1 | 20 | 9.995877 | 5.479180 |
| 0.22 | 20 | 10.341106 | 5.518125 |
| 0.1 | 5 | 11.022887 | 5.508395 |
| 0.22 | 5 | 8.958525 | 4.596926 |

两项单独修改都略差，组合修改才改善。这支持本固定划分上的参数交互解释，不能推出单参数普遍有效。
诊断是在唯一成功样本被观察后安排，不能充当新的独立验证；没有重开正式项目选择。

### 多花模型时间，还是多跑廉价搜索？

同一成功划分再做一次事后效率诊断：沿原随机种子和原生成器，将追加抽样从 8 扩至 128；前八个恰好复用原 R，新增 120 个训练。
列表在新增训练前冻结，分布未加入模型发现的 0.22 等参数；按开发集选择并保存后才确认留出结果。
146 个总抽样对应 136 个不同配置，全部有效；重复抽样没有被替换成更有利的候选。

| 方法 | 留出 MSE | 活动秒 | 模型费用 |
| --- | ---: | ---: | ---: |
| 原随机八配置 | 5.479180 | 54.7 | $0 |
| 扩大随机至 128 配置 | 5.275370 | 106.6 | $0 |
| 两轮模型反馈，八配置 | 4.596926 | 301.4 | $0.8741 |

扩大随机有收益，模型仍达到更好的质量；这是一项质量与时间取舍，未证明任何一方达到相同质量所需的普遍成本。
扩展秒数含旧 R 完整项目以及本次新增 52.0 秒，到结果写出为止；最终审计捕获另花约 0.3 秒。
该诊断只选了模型获胜的一组，执行时段不同，没有强制两方耗时相等，也没有据此建立通用停止规则。

## 实际信息利用与最小修复

六个 F 项目第二轮都至少有一次提示包含合格的首批四项完整观察；并非仅把“有反馈”写进规则。
四个非置乱 F 项目都出现过跨页后首批观察消失；三个随后重新定向读取，airfoil-1 的最终请求仍未包含首批观察。
在 breast-cancer-1-F 中，模型明确请求保留首批观察，旧实现仍先装满新页，返回 `research_evidence_view_limit`；模型再花一次请求把它读回来。

Pro `3d77bbe` 只调整两处容量分配：报告视图优先按请求顺序装入 `retain`，联合快照优先交替装入两个通道的显式保留记录，随后装入普通记录。
记录原顺序、全部 ID 诊断、游标进度、来源重验和 32 KiB 上限保留。空间不足可挤掉普通记录，过大或失效的保留记录仍不可用。
使用说明见 [证据分页](https://github.com/orze-ai/orze-pro/blob/main/docs/research-evidence-paging.md)（私有 Pro）。

真实完成项目的只读重放中，同一显式保留观察从 **unavailable → qualified**，完整首批数据一致；快照 **32236 → 31540 字节**，均未超限。
它替换了普通页的一条完整显示，所有 ID 和覆盖语义保留。重放状态已经含最终确认，只用于验证装入机制，未再输入研究选择。
先后单次计时不作为加速证据，也没有修复后模型质量的因果主张。

相关 **161 项测试通过**；最终五个回归用例在旧代码上有三个预期失败、两个通过，在修复后五个全部通过。
早期误写测试文件名导致的收集失败也保留。测试数不是研究能力指标。
另一个尚未解决的问题是模型主动换页时没有保留真正最佳方法：分类第二划分看过 1/111 的开发误差，最终提示却丢失它。
本修复尊重显式保留，不会自动证明模型正确使用了所有历史。
成功的 airfoil-0-F 首轮也只围绕可见页的 14.32 比较，首批最佳 10.63 仍差于完整初始历史中的 10.00。
它明确限定了可见子集，但局部改进并不等于推进了项目最佳值；第二轮的实际收益不能反过来证明前面的证据选择充分。

## 冻结设计、数据和中断

- 正常签名 Pro 许可和原生 research／CPU 链；Opus 5 high、8192 输出额度，每决定最多三次 HTTP 请求，420000 token 预留，无重试或 fallback。固定一／两轮是本次比较边界，不是自主收敛或产品总期限。
- 3 个任务 × 2 个划分 × 3 个方案，四项目并发；初始为六个标准方法加十二个冻结随机抽样。两个置乱初始列表各有一次精确重复，因此十八抽样只需十七次不同训练，所有方案同样复用已核验观察。
- 模型仅能选择有界声明式参数，固定数据、worker、动作与评价协议；每次拟合单线程、4 GiB、45 秒限制。批量最多八配置、每配置预留 60 秒，超量预检拒绝且零训练。
- 每项目原生预留 1740 秒：数据捕获 60＋十八初始槽 1080＋八新增槽 480＋两次确认 120。预留未用完也不退款；同一最终配置复用同一确认。两次预检强制不同确认配置只为走完整链，其质量不计入科研结果。
- Python 3.10.12、NumPy 2.2.6、SciPy 1.15.3、scikit-learn 1.7.2；训练和预处理只用训练行。模型选择只用开发集，独立逐行复算所有有效预测。

数据为 [UCI Airfoil Self-Noise](https://archive.ics.uci.edu/dataset/291/airfoil+self+noise)（Brooks、Pope、Marcolini，1989；DOI 10.24432/C5VW2C；CC BY 4.0）及 [sklearn Wisconsin diagnostic 数据](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_breast_cancer.html)。
翼型共 1503 行，按除频率外的四项特征精确分组：同一操作条件的各频率不会跨集。两次训练／开发／留出行数为 803／402／298、854／271／378，对应组数 58／27／21、61／19／26。
分类 569 行，按完整特征行分组，两次行数为 332／129／108、355／111／103。固定盐值哈希分配不使用标签或分数，独立数据审计从原始来源重新构建分组、目标和置乱。
没有证明物理重复测量或患者身份独立；分类只是基准实验，不涉及临床应用，翼型也不是新翼型形状泛化。熟悉公开数据可能已出现在预训练中。

原批次完成十项后中断：实验脚本误以为每个初始抽样都会插入新任务，遇到精确重复时没有复用 Core 正确返回的已有任务。
保留四个中断、四个未开始的记录与停止标记。两个 airfoil-F 的第二份模型计划当时已经返回，后来只补原计划的 CPU 训练和确认，**没有重新调用模型**，原响应／capture／run 字节未改。
剩余六个置乱项目在新目录运行，保持原抽样列表并复用重复观察；原失败设置时间计入对应 R／P。
这是编排错误，不能算成模型失败，也不能从总体成本删除。新预检覆盖重复抽样、两批反馈、两次确认和超量拒绝。
