## 推进与交付标准

优先完成两项 P1，再推进持久记忆、生产兼容和端到端验收。每片按“保留基线／失败 → 实现 → 定向与真实产品验证 → 两仓回归 → 独立核验 → 提交推送”闭合。

每次验证运行使用唯一的短 `--basetemp` 路径（例如 `/tmp/ov-c1`），避免 controller 夹具的 Unix socket 路径超限；首次失败及修改运行参数后的复跑均保留。

保留原始记录，不覆盖失败，不弱化业务断言；元数据测试与真实执行、局部性能与研究收益分别报告。涉及真实账户、费用、设备或现有服务的变更，先明确必要授权。
