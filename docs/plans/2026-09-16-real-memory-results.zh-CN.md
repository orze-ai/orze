# 真实模型记忆对照：研究结果、流程损耗与费用

**已完成真实模型筛查及修复后复跑；本轮尚不能证明持久记忆提高研究质量或降低单位有效结论成本。**
实验发现了两个直接妨碍研究完成的问题：开启记忆后误拒普通 Markdown JSON 提案，以及
实验入口把已追加提案误当成已获准执行的候选。已修复并分别保留前后运行。
这些修复消除了流程障碍；研究收益要由实际质量、重复错误、时间和费用判断。

## 设计与边界

用户授权所有可调用模型做实验，全部新实验的费用总上限为 5000 美元。首批选择 Sonnet 5
与 DeepSeek Flash；后者实际生成均返回 HTTP 402，保留全部失败，再单独运行可用的
Haiku 4.5。Gemini 的模型查询返回 403，本地既有模型接口未连通。

沿用[事先固定的四对设计](2026-09-16-memory-pilot.zh-CN.md)：两个本次新编写的小型调度任务，
各两次 AB／BA 配对；每个模型／版本一批 8 个项目，每项目 4 轮、每轮请求 2 个候选。
A 关闭持久记忆，B 开启；两边同样从空历史、空记忆开始，保留正常历史与证据分页。
实例、指令、模型、轮数、顺序与预算在每批运行前固定，不按成绩挑选样本。
种子只控制评价顺序，不控制远端模型的随机生成。

目标任务最优价值为 27，负面对照为 10；解与最优值不放入模型提示词。模型提出排程，
现有 CPU 评价器计算可行性及价值，最终选择再由独立原生 attempt 复验。
这是短上下文、小任务筛查，不是独立盲测、长程记忆或跨领域研究验收。

全部 8 个计划样本都有原件并完成核验。不能因为进程退出 0，就把无效排程算作成功。

两臂费用合计为 A 0.121861／B 0.170415 美元，实际模型尝试为 13／16 次；不同完成率下
不直接把臂总耗时或总费用相除称为效率改进。原报告的 `all_pairs_qualified` 仍为 false，
供应商账单、远端 GPU 和部分 worker 指标未知，不能声明完整资源成本已更优。

**B 的 4 个项目始终是版本 1 的空记忆，实际更新次数为零。** 观察到的成绩差异可能来自
额外提示词和远端采样差异，不能归因于保存与复用研究记忆。小样本不足以证明稳定优势；
前后修复批次也不是控制住远端随机性的旧／新版因果估计。

已评价的完全相同无效排程重复次数，两臂均为零；被原生去重留存的提案分别为 3／6 次。
它们是不同指标，去重提案不产生新科学观察。语义相同的错误仍存在：B 的一个目标项目
有三个不同排程被判容量冲突。B 另有一轮 `research_memory_response_invalid`，其原始模型
响应未单独保存，不能断言也是此前的 fenced JSON 问题；后续轮次完成，不删除这次失败。

## 实验驱动的两项修复

1. **记忆解析兼容。** 初始 Haiku B 的 16 轮均被 `research_memory_response_invalid` 阻断。
   一次单独的真实响应诊断取得整段 fenced JSON：普通提案解析器识别出两项提案，记忆
   请求分类器却拒绝整段响应。Pro `ef0ea36` 允许这种普通提案继续走原解析器；记忆写入
   仍必须为裸 strict JSON，fenced／嵌套／混合写入控制仍拒绝。原响应重放通过，相关
   115 项检查通过。单独诊断不计入四对样本；首次诊断忘记注册 Domain 的失败也保留。
2. **实验入口处理正常去重。** 在初始与仅修复解析后的原件中，9 个项目有已追加但未获准
   执行的重复配置。原入口仍期待每个提案有新产物，因此抛错中断。Core `f2f7281` 只在
   保留原文、当时数据库与规范化执行配置相符时记录 `retained_duplicates` 并继续；重复
   不增加科学观察或分数，调用／等待成本照计。未知缺失、已准入却没有产物及原生命令
   失败仍失败。可重复样例在旧版失败，修复后的完整流程、记忆、双臂批次等 8 项检查通过。

第一版去重测试误只改标题，未触发跨轮原生去重；其失败记录保留。改为两轮同配置后
才复现真实中断。没有根据真实模型成绩修改评价器、题目或成功标准。

## 费用与许可

费用根据实际用量日志及 [Anthropic 官方价格](https://platform.claude.com/docs/en/about-claude/pricing)
计算：Sonnet 5 输入／输出每百万 token 为 2／10 美元，Haiku 4.5 为 1／5 美元；同时
检查缓存读写计数。本次已定价返回中的缓存计数为零。DeepSeek 的
[价格页](https://api-docs.deepseek.com/quick_start/pricing/)仅用于事前保守预留，402 请求
不能按零费用补齐。估算不是账户账单，也不包含无法核实的请求费用。

包括早期中断、探测、单独诊断与所有批次，共记录 112 次传输准备、103 次返回；有完整
用量可定价的部分合计 **1.926541 美元**，输入 541,211／输出 160,423 token。另有 9 次
费用未知：8 次 DeepSeek 402 和 1 次未完整返回的中断／超时请求。未知部分继续由保守
额度覆盖，没有填成零或声称供应商账单已经核对。

每批设置进程 token envelope、固定模型与有限轮数，禁用跨模型 fallback；传输重试
共用该进程的 envelope。累计保守预留上限为 245 美元，包含失败、中断及未用额度，
**不是实际扣费**。没有充值其他账户或占用本机 GPU，没有更改既有服务。

Pro 密钥签名和期限通过，在线激活返回设备上限已满；正常许可代码随后允许有效签名
密钥离线运行。真实实验没有许可替身或绕过，没有停用其他设备；生产在线激活仍未验收。
