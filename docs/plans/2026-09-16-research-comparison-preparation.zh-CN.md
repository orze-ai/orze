# 研究收益对照：计量准备与未完成项

## 当前结论

新增独立的离线对照工具 `examples/research_comparison`，将固定任务／配对顺序、质量条件与计量归约分开。它不启动研究，不调用模型，也不修改产品停止策略。现有 Core／Pro 产品源码未修改。

已完成定向 96 项检查；从原始归档重新读取的 24 对／48 个历史 CPU 项目，全部九项指标的组中位数、配对差与已发布结果精确一致。另一个不导入产品、旧 qualifier 或新 reducer 的 stdlib 脚本从原始观察／终态／账本重算九项指标及覆盖代价，通过核验。这不是另一位审阅者，也不是新科研实验。

最终 Core 全量5,277通过、7项可选跳过；Pro全量1,563通过；配对31通过。输入冻结、原始输出、独立算术、私有探针归档和当前源码一致性均已核验。这只完成计量准备，整个 P1／P2／P3 目标继续开放。

## 工具能防止的计量错误

- 所有预定运行留在分母中；重复、多余、错种子、错 A/B 身份、错协议与重排记录拒绝，不筛掉失败。
- 指标由工作负载适配器从原始证据导出，不采用保存的成功标志或模型自报质量。缺失运行、核验异常和未知用量明确保留。
- 两臂共享每个任务的数据、评价器、指令、初始历史／记忆、种子和预算；模型、工具、环境及两臂制品／处理配置都有固定内容标识。摘要校验本身不证明输入已被执行使用。
- 质量需有效、经独立尝试确认、比较范围一致、达到预先规定的覆盖数，并满足 B 相对 A 的质量容差；未知或超出必需预算不能过关。
- 每组所有配对通过才生成组中位数；每列还要求全部配对有测量值。配对差取逐对 B−A 的中位数，不用两臂中位数相减。
- 失败调用的已知成本照计；`known_sum` 在 `complete: false` 时只是已知小计。没有用量不是零用量，不知道费用不能称免费。
- 负对照和覆盖变化单独保留；任务／领域不自动混合成一个有利总数。

## 历史复算的范围

唯一已接入的 CLI 适配器固定读取 2026-09-12 的公开排序／压缩对照。归档、原始 manifest／summary 和每份 `run.json` 都核对原哈希，直接读取 tar 成员，不解包或执行归档代码。

实际选择、独立 attempt 复验、完整引用、原生产物哈希、关闭／结算与时钟仍由既有 qualifier 从记录导出；新工具另保存当前核验代码的 SHA 库存。历史固定数据没有随机种子，所以种子为 null，不虚构已运行种子。

结果仍是两个默认任务动作数 5→4，两个反事实 3→3；原始 180 个 native attempt，不新增 CPU worker。A 的观察总数为 valid 72／invalid 12／unknown 12，B 为 60／12／12。少取得的十二份有效分析没有被隐去。首次有效证据仍没有一致提速。

历史记录没有实际 provider 用量／账单或 GPU 时间账本，因此对应列保持未知。历史 CPU-only 声明没有被转成新测量的零 token、零美元或零 GPU 秒。所有复算报告的 `new_research_evidence` 固定为 false。

## 已保留的失败

1. 新模块尚不存在时，定向检查在收集阶段失败，退出 2；用于记录缺少功能，不称旧产品缺陷。
2. 首实现 86 通过／1 失败：新测试夹具把最后缺失的 B 臂误写为 A；修正夹具后增加顺序、方向、容差、覆盖及 JSON 边界，最终定向 96 通过。
3. 独立算术核验首版误把账本纳秒十进制字符串当作数值求和，退出 1。原脚本／日志保留，v2 显式转换后通过。
4. Pro 全量启动命令未指定 `tests/`，误收集证据归档中的旧测试，132 项收集错误、退出 2。未删档或改测试；新的运行明确指定正式测试目录。

上述失败不计作历史科研实验失败，也不与最终验收结果混合。

## 真正的研究收益仍需要什么

当前 `check` 只检查协议结构和固定顺序；它不会证明预注册时间、输入可用性、实际花费、模型许可或执行授权。真实任务的工作负载适配器尚未实现，真实模型实验尚未运行。

下一轮需要固定实际研究任务、独立评价器与质量容差、初始状态、模型／提示与工具配置、两臂制品、种子、完整调用／费用／计算额度，以及失败／重试计费和外层验收关闭规则。先验证等质量，再比较首次有效证据、确认结论、完整项目耗时、费用、失败和未知结果。有限验收预算不改写 Orze 的自主继续／停止策略。

当前研究费用日志还存在离线复现的前置缺口：缺失 token 用量与明确零用量不可区分、失败重试缺少对应记录、非法 token 类型被转换为数值。后续先修正这些问题并接上当前消费者的实际调用身份；保守 token 预留不能替代实际用量或账单。此处没有据此宣称真实账单少记了多少。

真实任务方向、模型／账户和费用授权仍待明确。既有 CPU 示例不能作为新的独立留出任务，离线替身不能证明模型利用记忆或反例的能力提升。
