# 用全部八张 GPU 验证真实研究目标

状态：16 个实例已全部完成并独立核验。旧策略平均封顶达标时间 60.38 分钟，组合 73.63 分钟，两组均通过 5/8；按主目标保留旧默认。详见[完整结果](2026-09-22-real-gpu-results.zh-CN.md)。以下保留启动前协议。

用户优先级是达到可靠研究目标的实际时间。上一轮合成任务的事后审计提示早期候选有价值，却没有测量在线验收和提前交付。本轮直接执行这一闭环。

## 任务与对照

- 四类真实英文语音：LibriSpeech other 有声读物、AMI 单远场麦克风会议、TED 演讲、FLEURS。
- 使用本地缓存的原始训练分片，新建确定的数据划分。每个实例含训练 512、开发 96、两份独立确认各 128、最终验收 256 条音频。四题各两次重复，共八个数据实例、8960 条选中记录；重复间可能重叠，不能称为 8960 条独立来源样本。
- 每个实例比较旧 `ParallelRefine` 与 `BreadthThenAdaptive(Dream4, min_steps=2)`，共 16 次研究。两轮各八个实例并发，每个实例绑定一张 A100；第二轮交换两种策略使用的 GPU。
- 同一 Whisper-small.en 244M 预训练模型、同一 claude-opus-5/high 研究模型。每次研究最多 14 个方案／诊断、4 条分支、深度 6、两小时目标窗口。
- 可以修改表示、适配器、损失、正则、数据选择／增强、解码和诊断方法；没有限制为超参数搜索。只提供分支自身历史，保留失败结果。

这是共享 GPU 条件下的真实 ASR 域适应验证。**不是 1.7B 项目的最终验收，也不足以代表所有研究领域。** 模型规模、数据范围和实际资源约束必须随结果一起报告。

## 公平且有实际意义的基线

每个实例先比较原始模型与固定 LoRA100（100 步、lr=5e-5、rank=8、q/v 投影），用开发集更好的一个作为两组共同参考。固定微调只改善 2/8 个实例，另外六个使用原始模型；因此正式目标不是“比未经检查的弱基线好一点”。全部校准已在八张 GPU 上跑完，选择规则未使用确认／验收成绩。

固定 LoRA 在 AMI 重复 1 将开发 WER 从 39.14% 降至 38.69%，在 TED 重复 0 从 15.43% 降至 14.95%；其余六个实例变差。研究阶段要求相对这个共同参考再降低至少 10% WER。

初次校准遇到镜像中可选 torchao 与 PEFT 不兼容，八个任务都在训练前失败。已保留失败记录，在独立研究镜像中移除不使用的 torchao 后重跑校准。没有修改宿主机或现有应用依赖，也没有为校准发研究模型请求。

## 直接测量交付时间

新开发最优候选若达到 10% 相对提升，可使用下一份独立确认数据。最多两次，每次数据不复用，只反馈是否合格。合格条件同时要求：

1. WER 相对参考降低至少 10%；
2. 5000 次配对组 bootstrap 的差值 97.5% 上分位数小于 0。

首次通过确认的候选立即接受最终验收；验收通过或拒绝都结束这次有界研究，最终数据只使用一次。如果预算或时间耗尽前未进入最终验收，则对开发集最好的有效改进方法做一次最终验收；没有有效改进则保留基线并计失败。

主指标是**最终验收通过时的实际墙钟**。模型等待、失败、训练、确认与验收均计时；超过两小时或未达标统一记满 7200 秒。先平均题内两次重复，再对四题等权，避免仅报告成功者。正在执行的动作可能越过截止时间；实际超时单列，迟到的通过不能变成窗口内成功。

共同数据准备、运行环境建立和基线校准在策略计时之前，单独报告。正式运行记录会保留模型调用、GPU 利用率、失败和有效诊断；特别区分第 9 次之后的自适应分配与之前两组相同的广泛探索阶段。

## 边界与解释

确认／验收的参考文本不挂载到候选容器；训练与开发可见性按任务类型分开。LibriSpeech、TED 按 speaker 分组，AMI 按 meeting family，FLEURS 按 sentence id。后两者**不能保证说话人独立**，AMI 某些确认集组数很少。bootstrap 是描述性不确定性估计，不是有限样本错误率保证。

现有 Avatar／语音服务保留运行；研究共享全部八卡的剩余资源，每任务 PyTorch 分配器上限约 6 GiB、2 CPU、12 GiB 主机内存。GPU 干扰无法完全消除，交换设备和遥测只能帮助解释。所有生成程序在无网络、只读根文件系统的独立研究镜像运行。

只在 16 次研究全部完成且原始预测、检查点、时钟、容器关闭状态与费用核验通过后比较均值。完整协议按更低平均达标时间且验收率不下降选择候选，平局保留当前默认；同时报告四个问题层面的区间、确切符号翻转结果和适用范围。不能把自适应开始前的随机差异解释成 Dream-RSI 的机制收益。
