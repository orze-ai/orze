# 单文件已消费 ID 提示：减少跨页 YAML 解析

基于 Core `e5289587a0c4aa445cfc420d77b7e174a9c24c03`、Pro `f7ba224a01aa13d8d0739873def24f5272b3ba5e`。已消费但尚未完整走完的一个 sidecar 文件可保存 ID 前缀；续页仍读完整当前文件，确认同一身份后用这些 ID 跳过旧前缀 YAML。两轮 5,000 条单文件完整 ingress 约 17.58→3.81 秒、17.81→3.84 秒。独立文件对照基本持平，包含轻微退化。

## 实现与失效

完整文件和最多一个部分文件共享 8,192 文件／32,768 ID／1 MiB ID 字节提示容量。只在首个未缓存文件且前面的已验证前缀仍连续时保存；当前读非空、同名、身份匹配和已消费数量不大于 offset 都是复用前提。缓存只含文件身份与 ID，不含 YAML、raw、准入结论或执行权。原 parser、ingress、源锁、writer 与 ACK 源码均未改动。

只有 yield 被下一次恢复后，该记录才计为已消费。达到记录或 raw 字节上限时，多取的一条 lookahead 不进入提示。关闭生成器时才保存部分提示，避免普通一条一文件路径增加逐页提示发布 I/O。clear 的代次令牌阻止异常清理后 close 再把旧提示写回；部分文件身份在当前批次复核与关闭发布处检查。完整文件的原有缓存发布和容量回退保留。

文件／目录／主源变化、改写并恢复 mtime、替换、链接／删除、读取失败、parser 异常、向后 offset、容量不足和未确认前置文件均有保留当前行为的验证。当前文件即便最终没读出内容，也不能靠旧 ID 建立优先级或推进到下一提案。

## 保留的失败与行为验收

- 104 项既有基线通过，71.56 秒。
- 新成本检查在原件上失败：续页 parser 的 seen 仍为空、重复解析已消费前缀。读取失败负对照通过；合计 1 失败、1 通过、20 未选择，4.12 秒。原件输出保留。
- 隔离 v1 原型曾在空读时复用 ID，错误接受后续尾项；22 通过、1 失败。v2 增加当前非空读前提后 23 通过，另 17 项边界检查通过。失败代码、命令、输入指纹、日志与 JUnit 均保留。
- 正式版本新增 22 项检查；定向总计 126 通过，119.70 秒，所有旧测试保持原件。
- 64 对完整 ingress 差分覆盖四种文件布局、八种来源变化／空读和正常／受限提示容量。运行内比较旧／新逐页完整输出，保留共同摘要；完整数据库和当前源文件一致。每个输入的原始字节、变更方案及最终文件保留。此组导入 completed 元数据、冲突 writer 保留提案，不等于真实执行。
- 两个独立 CPU 项目分别采用多文件／单文件，各导入 299 条 completed 元数据；真实 ingress 三批 128／128／45，第三页才接受尾项，重复提案保留。两个真实 worker 输出 `[1, 3, 5]`，核对 TREE_CLOSED／ECHILD_WALL、SETTLED 和产物 SHA；六次独立 CLI 启动含初始化、执行与回放。回放四张表无新增执行／扣记／产物，作者源不变。

## 解析、读取与内存

单文件 5,000 条：YAML 109,879→10,039 次，完整载荷读取仍为 40 次／54,155,600 字节；5,000 次正常 BEGIN／ROLLBACK 不变。文件身份检查 42→197，新增检查单列为代价。单文件 1,000 条 YAML 5,591→2,007，身份检查 10→37。独立文件的 YAML、载荷、身份检查与正常 writer 次数都相同。目录窗口与标题匹配数保持一致。
