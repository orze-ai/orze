# 新任务真实研究：产生候选与最终选择分开检验

## 结论

这轮使用此前未跑过的 Auto MPG，执行两组固定划分及其标签打乱对照。模型先做两轮代码研究，再明确选择一个已有候选；全部选择冻结后才捕获留出数据并全池重训。

- 自动取最低开发误差 D 对初始128候选最佳 B：真实任务 **1好／1同／0差**，负对照 **0好／2同／0差**。
- 额外模型选择 M 对同一候选池的 D：真实任务 **1好／1同／0差**，负对照 **2好／0同／0差**。
- 4/4 个项目有合法最终模型选择；1/4 与 D 的最终完整预测相同。额外选择阶段累计 **238.02 秒**，其全部调用和费用保留。

**具体进展：模型最终选择在两个真实划分都优于初始128候选最佳，留出误差分别减少14.00%和5.77%。** 第二个划分的三模型平均程序开发MSE为9.0704，略差于自动赢家8.9152，但实际全池重训留出为7.5011，优于7.9604。提供“明确选择已有候选”的动作解决了本案例中候选已有却未被选中的问题。第一个划分则由第一轮四模型等权程序获得收益，最后一次判断保持同一选择。

**效率仍有明确欠缺。** 四个最终选择调用加原生动作累计238.02秒；没有完整的等质量省时结论。两次负对照合计三份新程序在开发集上完整预测与早已存在的均值基线相同，最后仍直接选原基线。后续应检验让模型更早选择“已有方案足够／结束并确认”，减少重写已有结果；本轮没有把这一推测升为默认停止规则。不同训练程序在扩大训练池后可能分歧，开发预测相同也不证明全场景等价。

这只是一个新公开任务、两个重叠划分和四条短研究轨迹。正向结果支持相应候选的本案例用途；不能代替长历史、记忆利用、跨领域或稳定等质量效率验收。原交接六项继续开放。

## 全部冻结结果

MSE 越小越好。B、D、M 都以相同训练＋开发行从头重训；同一算法只确认一次并共享完全相同的结果。模型可以明确选开发误差较高的候选，执行器不会再用开发最小值否决该选择；空／非法／失败选择按预先规则回退 D，并保留失败。

## 实验定义与能力边界

每个项目实际执行相同定义的128个初始候选：124个固定／随机标准估计器配置和4个通用程序；精确重复身份复用预测。随后 Claude Opus 5 high 最多两轮各提交一个新训练程序，后一轮看到前一轮的实际结果。第三轮只能选已验证历史中的候选 ID，不允许悄悄增加程序或训练。最终选择动作重新核对身份、样本顺序和开发误差，直接复用已有预测，因此没有额外开发拟合。

D 从全部有效候选中按开发 MSE 最小选取，同分保留较早者；M 是模型显式选择。两者共享相同候选池，M 多付一次决策调用。这个设计检验最终决策的增量价值；没有声称单因素隔离两轮研究的每项程序机制。候选产生、开发排名和实际重训后的质量分别报告。

每轮提示提供全部有效配置／完整程序、真实误差、精确失败反馈及训练／开发诊断。共享的过往经验明确标注来自其他任务，未提供本轮留出事实。提示容量预检额外留出两份最大程序的空间；本实验每轮仅一次 HTTP 请求，不是分页或持久记忆的独立检验。

模型源码先完整检查允许的操作，再按原始字节执行，不修补科学方案。单 CPU 线程、4 GiB、每候选45秒，numpy／sklearn／math；正常签名 Pro 和原生 CPU 来源／结算接口。ASR 只读，GPU／服务保持。

## 核对模型给出的研究理由

最终质量改善，不代表每条解释都已证明。第二个真实划分的新程序将标准候选固定的 boosting 160轮改为100轮，同时增加 log 目标成员和 SVR；因此不能把收益单独归因于等权平均。模型把两个同数据程序的相同输出说成“独立收敛”，也不能作为两份独立统计证据。均值预测不依赖输入特征，不等于估计器跨训练样本零方差，留出MSE还包含训练均值估计误差。这些原始解释保留为模型假说，评分来自实际预测。

## 数据和盲评边界

[Quinlan (1993), Auto MPG, UCI](https://archive.ics.uci.edu/dataset/9/auto%2Bmpg)，DOI `10.24432/C5859H`，CC BY 4.0。原文件398行，预先排除6行缺失 horsepower，使用392行、七个数值编码特征预测原单位 mpg。origin 是类别编码，车名未用。文件 SHA、下载来源和完整分组写入清单。

完全相同特征向量按组划分。按冻结 SHA 字符串排序，约60%训练、20%开发、20%留出，每个正式划分实际234／79／79行。对应负对照分别在三个集合内部按固定种子置换标签。负对照身份在提示中明确告知，不能把模型选择简单基线当成自主发现无信号。独立审核从原始文件复建特征、标签、分组及完整训练池，确认没有组跨集合。相关车型仍可能跨集合，不是独立车队或未来年份测试；两个划分重叠，不能当作两个独立总体。

预演使用另一个固定划分，无 API 调用，实际验证合法选择精确复用、不存在的 ID 记为失败、完整提示和冻结后确认。正式项目在预演后使用新身份；正式留出只在全部选择冻结后被捕获。
