# 先确认收益的边界：固定配置复算与研究判断检查

## 结论与决定

**已有单次收益成立，稳定迁移的证据不足；增加两条提示指引也没有稳定解决后续实验设计问题。**

冻结此前获胜配置及参照，不再搜索，用每个数据集八个新分组划分配对复算：
翼型组合只在 **3/8** 次更好，中位误差增加 **5.99%**；混凝土 L2 改动在 **5/8** 次更好，中位误差减少 **2.45%**。
原先的 16.1%／4.64% 仍是各自原划分上的有效观测，不能把它们当作稳定跨划分收益。
本轮没有重新运行自适应研究策略，因此也不能据此断言该策略整体更差。

这轮完成 32 个 CPU 项目、96 次固定拟合，经过 **49.0 秒**，无模型调用。
随后用两种真实模型检查原提示 A 与两条新增比较指引 B，共八份决定。
B 有一处更明确识别双参数改动，但仍出现独立性、比较分母、负对照和后续选择设计错误；四对都更慢、费用都更高。
**新增指引不合入默认提示词，不再围绕这两个案例反复改提示。**

下一步应让研究动作明确返回实际参照、参数差异、样本重用关系和选择／确认的分工，再测真实决定与执行结果。
这次没有新增产品执行框架，也没有把固定八划分设成默认研究要求。

### 实际改动和交互

- 翼型固定 `boost / scale=none / max_leaves=15 / l2=1`，比较参照 `learning_rate=.1, min_leaf=20`、原获胜组合 `.22, 5`，以及两个单因素配置；其余拟合设定相同。
- 混凝土固定 `boost / scale=none / learning_rate=.2 / max_leaves=31 / min_leaf=5`，只比较 `l2=1` 与 `l2=3`。
- 翼型单独改学习率在 3/8 次更好，单独改叶样本数在 2/8 次更好。交互量 `L联合-L学习率-L叶大小+L参照` 仅 4/8 为负，不能推广原划分上“联合变化才改善”的解释。
- 置乱的是每个 split 内的目标值；特征、配方／工况分组和组成员均保留。不能说分组结构被删除。
- 负对照去掉有意保留的特征—目标关系，并不要求两个拟合方法的误差差为零。正则化与模型容量仍可能改变对噪声的拟合；有限样本中的几次获胜也不是恢复真实信号。

## 测量设计与限制

复用此前已归档的 UCI [Airfoil Self-Noise](https://archive.ics.uci.edu/dataset/291/airfoil+self+noise)
及 [Concrete Compressive Strength](https://archive.ics.uci.edu/dataset/165/concrete+compressive+strength) 原数据。
各有 1503、1030 行；翼型按四个非频率特征分组，混凝土按七项成分的相同配方分组。
对 `confirmation-20260917-{rep}:{group}` 做 SHA256，前八位模 1000，<600 训练、<800 开发，其余评价。
rep 为 0–7；开发部分保留但不用来选择。目标置乱种子为 `2026091791+rep`，按训练／开发／评价顺序分别置乱。

候选、全部划分和原件哈希在新拟合前固定。每个配对用相同训练和评价行；160 次 boosting 迭代、固定种子1729，预处理只拟合训练行。
每次拟合单线程、4 GiB、45 秒；原生预留为数据捕获60秒加每候选60秒。四项目并发，未改 GPU、ASR 或服务。
没有重新选择候选、调整阈值或挑选表现最好的新划分。

这是已选配置在同一数据集中的敏感性分析；没有独立新采集数据，也没有复跑完整模型研究策略。
随机划分可用于针对固定数据的条件性分析，但不能把这种目标悄悄替换为新数据总体上的独立复现。
若要评价包含选择步骤的研究流程，选择须在训练／内层验证中进行，外层评价用于检验整个选择过程；
参见 [scikit-learn 的嵌套交叉验证说明](https://scikit-learn.org/stable/auto_examples/model_selection/plot_nested_cross_validation_iris.html)。
模型已经见过本轮数据或结果后的新设计仍属后续探索，不能追溯改称此前已独立确认。

逐行重建分组、输入及置乱后，独立复算全部96份预测，核验96个原生进程闭合和128份产物。
全部项目活动时间合计 **186.1 秒**，实际拟合／预测壁钟合计 **16.3 秒**，并发经过49.0秒；活动时间不能相加当作经过时间。
准备至执行结束的记录为 59.1 秒，包含冻结后的间隔，未包含此前脚本设计和后续整理。
完整资源／人工成本仍未货币化，不能据此宣称完成等质量端到端提速验收。

## 两条新增指引的真实消费者对照

原提示 A 对照 B，B 只新增两条：先核对实际参数变化再归因；重划已用于选择的数据不能创造独立验证。

实际判断中值得保留的问题：

- 两种模型都能读出大部分原收益和新划分的方向；Sonnet 的 B 更明确指出混凝土第四项同时改了学习率与L2。
- Sonnet 翼型 B 把“单因素优于参照”的计数读成“优于联合配置”；一句归因提醒没有保证比较对象正确。
- 部分回答一面承认数据重用，一面又把同一来源的新划分称为独立确认。Sonnet 翼型 A 提议对八个分数做符号检验／bootstrap，却没有明确是在推断固定数据上的随机划分性质，还是新数据泛化。
- 混凝土 Sonnet 的 A/B 都要求真实与置乱任务同时出现正改善；Opus 有回答因置乱组也获胜而质疑负对照是否有效。这些要求混淆了无特征信号与两种拟合方法无差异。
- 部分回答要求把联合优化候选一律拆开，或提出在已看过的八个划分上搜索新候选后直接采纳；没有正确分开解释范围、选择和确认。

不把这八份事后案例评估汇成通用正确率，也不把局部文字改善称为研究产出提升。
