## 两个已知领域与反事实

两个领域共用同一 Policy 源码、配置参数和请求形状。Policy 不按领域名、数据特征、预期指标或已执行次数选择赢家。Domain 配置承载数据；同一领域的反事实只改变该数据，不改算法、有效性判据、策略、阈值或预算。

| 领域 | 默认数据 | 三个候选 | 唯一反事实数据改变 |
|---|---|---|---|
| 确定性排序 | `[]`、`[5]`、`[1,1]`、`[0,1,2,2,4,3,5,6]` | baseline 插入排序；challenger 原样输出；unchecked 选择排序，初次不判科学有效性 | 最后一组改为 `[0,1,2,2,3,4,5,6]` |
| 无损编码 | 64 个 A、一个 NUL、64 个 B | baseline RAW；challenger 去掉 NUL 再 RLE；unchecked HEX，初次不判科学有效性 | 仅去掉输入中的 NUL |

排序指标为实际 comparator 调用次数，含返回 False 的比较，不计循环条件、拷贝或 Python 指令。必须保存并独立检查比较 trace、完整输出与重数。默认 baseline/unchecked 预期为 9/29 次；这些是预期值，必须由真实执行测量，不预填为测量结果。有效性仅对声明的有限测试集成立，不证明算法普遍正确。

编码指标为完整容器字节数，包括 4 字节 magic、4 字节声明长度及全部 payload。RAW、RLE、HEX 使用明确版本的严格 decoder，拒绝长度不符、尾随垃圾和非逐字节 round-trip。默认 RAW/HEX 预期为 137/266 字节；去 NUL 的 RLE 虽小但默认数据无效，反事实输入下才有效。不能只计净 payload 或把丢字节当压缩收益。

## 必须由实际证据改变的路径

默认路径：策略提出 baseline 并执行 → 提出 challenger 并执行，得到正常完成但 invalid 的诱人小指标 → 提出 unchecked 并执行，得到正常完成但 unknown 的观察 → 使用刚产生的三个 artifact IDs 提出并执行分析 → 新的 valid-but-worse 观察 → 对合法较优候选作同请求 Replicate → 副本真实完成/结算后主动 Stop。共 5 个实际动作。

反事实路径：baseline → challenger，后者经同一领域判据变为 valid 且更优 → 对其精确完整 Ref 作 Replicate → 副本真实完成/结算后主动 Stop。共 3 个实际动作；unchecked/analysis 请求、reservation 和执行均不得产生。

每次关键决策保留实际 snapshot 摘要、采用的 observation IDs、完整 Ref、有效性、比较范围、指标和决定。必须检查具体被选对象及决策依据，不能只检查 5→3 的数量或 `decide()` 返回字符串。候选初始探索顺序是这个示例策略的显式先验，不是 core 的领域规则或无限研究算法。

invalid/unknown 均是动作正常完成后的领域结论，不得用坏 envelope、缺产物或执行 HOLD 代替。分析生成新的观察和 evaluator occurrence，不改写原 unknown。副本 raw config/spec 不加盐，task/attempt/artifact/observation 独立；独立 occurrence 不自动等于统计独立。

补充明确标注的纯 Policy 反例：在真实捕获 snapshot 的副本上，让 unknown 的指标最优仍不得选为已验证赢家；保持 ID、顺序、数量不变而改变 valid 数值应改变选择。它们只证明决策逻辑，不是实际执行或授权证据，不加入实际动作数。

## 预算、计量与故障边界

每个动作 2 秒 wall envelope、每次运行 1 个 CPU slot、10 秒声明预算。四次已知领域运行合计 16 个实际动作、32 秒已预留额度；不退款，不把未使用的运行上限算作实际预留。默认路径虽恰好耗尽额度，最终必须是读取副本证据后的策略主动停止，而不是预算耗尽兜底；反事实 Stop 时应剩 4 秒额度。

记录 worker CPU/worker wall、native terminal elapsed wall、完整 CLI wall、预留额度、控制步骤和有效证据到达时点。整体 wall 减 worker wall 的差额不能称为纯框架 CPU 开销，不能据此宣称普遍节省百分比。持久 Stop 后重跑不能产生新 GO、attempt 或预留。

保留既有失败/中断/来源篡改/提交不确定测试及完整旧配置回归；这四个成功路径不替代 HOLD、恢复或故障证明。新增示例的 negative/unknown 是科学语义，和执行故障分开记账。
