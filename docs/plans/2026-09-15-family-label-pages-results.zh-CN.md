# 按合格 ID 分页读取家族标签

基于 Core `354faa71264ba04dea3466c615c2778d0786fd1d`、Pro `e701e66cc87936efc8d29518c218c8b8c7d2159a`。家族统计和家族失衡 guard 原先为少量合格结果加载全部完成记录的家族映射。本片改为按合格 ID 每页查询最多 128 行；资格核验、统计内容与决策阈值保持原有规则。

## 实现与边界

Core 扫描器增加请求家族标签的模式，与原 ID 枚举互斥。沿用 1–256 的可配置页大小；Pro 两个消费者使用默认 128。请求使用不可变 ID 集合，每页按该集合的迭代顺序返回标签；沿用旧 ID 路径规则和家族名称规范化，不换成更严格的新提案 ID 格式。数据库策略、全局身份结构检查、路径／版本复核和读后释放事务沿用原扫描器。缺失或不再完成的请求项、分页期间提交或路径变化拒绝整个结果；最后一页之后到正常退出之间仍复核。回滚不被当作已提交变化。

Pro 的家族统计和失衡 guard 仅在完整退出后使用聚合结果。并列成绩沿用原不可变集合顺序，浮点求和仍在相同家族内按原顺序调用内置 `sum`。前十分位仍完整排序再选择，资格 ID／值、分组值列表仍随合格历史增长；本片限制家族查询页面和临时标签，不构成整个过程的内存界限。单个 ID、原始家族字段和报告的大小仍未获得新的字节硬上限。

指标资格核验和之后的家族标签读取仍是两个阶段，不是指标文件与数据库的原子联合快照。每个候选仍核验资格，标签分页不授予执行权，也没有缓存旧标签。公共全量家族入口保持原有行为。

搭配缺少新方法的旧 Core 时，两个消费者返回固定的“家族证据不可用”诊断。这个兼容分支在首版配对验证后发现并补齐；修改前源码、测试、产品与计时原件另存。

## 基线、失败与行为验证

- 既有基线：Core 79 通过，5.12 秒；Pro 54 通过，10.32 秒。Pro 首次启动遗漏隔离测试进程的许可证替身，收集阶段 3 个错误，0.40 秒；原日志保留，重新启动未改产品许可证逻辑。
- 旧成本检查：两个消费者均为 129 个合格 ID 一次取回 2,500 行家族标签，2 个预期失败，0.74 秒。
- 新增 Core 25 项、Pro 14 项。Core 定向 104 通过，12.52 秒；Pro 首版 64 通过，17.15 秒。兼容缺口另有 4 个异常失败；修正后 Pro 定向 68 通过，11.79 秒。原有测试文件保持原件。
- 最终 32 对完整输出／诊断差分使用固定的合格快照输入，隔离比较标签读取与聚合，覆盖方向、并列、浮点抵消、标签规范化、缺失列、状态／阶段冲突等，并保存映射顺序。实际资格读取由定向测试、产品路径及成本夹具另行验证。另有五种分页期间提交／回滚检查。首版正式差分及原型差分也分别保留。
- 原型首次输入指纹误含正在写入的日志，末尾断言失败，未保存完整比较输出；复跑修正输入范围并逐项保存。原型首次完整上下文探测还因延迟导入超出测试许可证替身作用域而失败，两份原脚本及夹具均保留。

## 实际产品路径

两个独立项目各有 260 条导入完成历史，architecture／data 各 130 条。第二个项目仅将一个 architecture 结果标为不合格，合格计数变成 129／130。实际演进 CLI 生成的提示词因此把主要家族从 architecture 切换为 data；同一个本地确定性 provider 程序读取实际提示词后，选择另一家族生成原生 CPU 提案。

最终两次 CPU 执行经正常提案源锁、ingress、worker、关闭及结算完成，产物保留观测计数、选择的家族与当前父来源。六次独立 CLI 包含新进程重放，四张表没有重复执行或扣记。观察器记录标签页为 128／128／4 与 128／128／3，没有调用全局家族映射入口；不合格 ID 不出现在标签页内。

首次产品夹具完成一个 CPU 动作及重放后，末尾观察断言把提案字典当成列表，出现 `KeyError: 0`；完整报告、独立的回放前表快照和逐次退出码记录未保存，该限制与实际文件一并保留。修正观察器后的首版配对执行两个动作，补齐旧 Core 兼容后又在全新项目完成最终两个动作。本片共保留五个实际 CPU 动作，最终验收使用最后两个。

这些历史是导入元数据，provider 是本地确定性可执行程序。实际 CPU 动作证明信息传递、执行与恢复链路，不等于真实模型或科研收益验收。没有真实账号、GPU 或既有服务变更。

## 回归与核验

共封存 15 份归档、69,801 个文件。首次归档预检要求探索目录有总报告，但原型根目录及两处失败探索没有写出总报告；预检在创建归档前停止，原日志保留。第二版归档器核对既存的完整运行记录后归档，这些目录保留原状，未补写原运行报告。

Pro 一次全量 1,194 通过，304.20 秒；配对 31 通过，0.74 秒。Core 一次全量 5,046 通过、7 可选跳过、2 既有 warning，1,064.05 秒。集合有重叠，不能相加。独立进程机械预核验已通过，SHA-256：`37f2b8da04b4e09a5daf6c07382780c40646e8ed3c7b642c27286e94017eadc5`；核对 282 个未改 Core 源文件／525 个既有测试文件、94 个未改 Pro 源文件／148 个既有测试文件。它不是另一位审阅者。最终机械核验通过，`verification.json` SHA-256：`aecc9d70e42796fe3055ee37bcd62167b4834c96c0a17080d4f35e2175666947`。

公共仓库保留自身基线、日志和[私有证据索引](../evidence/2026-09-15-family-pages-pro-private-index.json)；私有源、原型与两仓指纹留在 Pro 私有仓库。
