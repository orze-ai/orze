# 原生 CPU 注册停止：实现与验证

新增显式 `controller_control: {version: 1, profile: local_cpu_stop_v1}`，
把原生 CPU 主循环接入既有控制器登记和停止观察者。此前 CPU 模式拒绝全部控制器配置；
现在可以核验本实例全部动作、后代、预算及数据库关闭，并等待登记进程实际退出。
默认关闭，既有 GPU 配置保持原合同。[使用方法](../cpu-controller-stop.md)。

## 关闭证明

原生动作结果提交与 CPU 预算结算是两个事务。控制器成员已 SETTLED，不能单独证明预算已结算。
新增核验把全作用域预留与精确动作引用、终态和 effect 回执对应；没有 attempt 的 RESERVED
预留同样阻止确认。ACK 事务再次读取预算，外部停止观察者独立重验；任何未知保留 HOLD。

CPU 控制器使用真实登记、出生身份和 pidfd，不新增兼容 PID 文件。普通第二次启动会被保留的
登记拒绝。主循环、动作监督器、SQLite 和策略消费者均沿用原路径。

## 实际执行与故障控制

最终新增 19 项检查通过，其中七个隔离产品案例实际运行 CLI，
产生五个原生 CPU attempt；四个 completed，一个主动停止后 interrupted。
主动停止案例另启动一个后代，并在停止返回前核验 worker、后代和旧控制器的内核句柄均已退出。
这些次数不包含全量回归中再次执行的同一批测试，不能相加为独立研究结果。

| 案例 | 原生尝试 | 预算状态 | 停止确认 |
| --- | ---: | --- | --- |
| 空队列自然退出 | 0 | 无预留 | 有 |
| 动作自然完成 | 1 | SETTLED | 有 |
| 外部 CLI 停止 worker 及后代 | 1 | SETTLED | 有 |
| 持续授权与运行期租约 | 1 | SETTLED | 有 |
| 模拟漏掉预算结算 | 1 | BOUND | 无 |
| 孤立预留，没有 attempt | 0 | RESERVED | 无 |
| 数据库关闭响应丢失 | 1 | SETTLED | 无 |

外部停止案例在确认后故意修改结算哈希；观察者重新核验时拒绝。
归档保留了修改后的数据库，独立检查器明确按原终态重算原摘要作对照，不修复或覆盖原件。
自然退出的两个案例还实际重跑普通入口，均返回 75，未新增执行或预算记录。
GPU、旧停止函数和 provider 探测在子解释器中设为禁止调用；Pro 许可发现使用离线替身。

## 回归与保留的失败

- 既有基线：91 通过。旧代码面对四项新能力要求实际四失败，原因是新 profile 尚未支持；不称作四个历史缺陷。
- 首实现：两通过、两失败。旧 PID 写入函数留下兼容别名；CPU 注册路径去掉该写入后修复。
- 中间定向：114 通过；最终相关检查：137 通过，包含全部 19 项新增检查。
- 第一轮 Core 全量实际 5,356 通过／1 失败／6 跳过：CPU 分支直接读取可选属性，使既有存储边界测试中的轻量控制器报 AttributeError。改为缺失时默认关闭；原测试与断言不变，首轮全量和修复前快照完整保留。
- 最终源码 Core 全量：5,357 通过／6 项跳过，1158.12 秒；Pro：1,647 通过，464.83 秒；配对：31 通过。集合存在重叠。

所有运行均固定源码；首轮失败、修改前输入、各候选、JUnit 和原始产品目录均保留。
中间测试稿由最终稿重建后与该次运行的冻结 SHA 精确匹配，单独标为 recovered。
独立 stdlib 进程核对基线 Git 内容、当前源码、归档字节、五个终态／回执及预算／成员摘要；
这是机械复核，不是另一位审阅者。Pro 源码、测试和示例未修改，配对库存留在私有仓库。

## 剩余范围

本片只完成 CPU 注册停止。预算证明是单实例全作用域摘要，尚不能用于跨代历史。
CPU 一次性交接、service/watchdog 进程所有权、服务隔离与迁移回滚仍待完成；
匹配路由下裸 PID 可被 watchdog 当作终止目标的既有反例仍未由本片修复。
确认关闭不授予重启、接管或第二次执行许可。停止核验增加读取成本，本片没有研究提速测量。

没有真实模型、GPU、已有服务或部署操作，没有新的等预算研究质量结论。
原始 P1／P2／P3 总目标继续开放。
