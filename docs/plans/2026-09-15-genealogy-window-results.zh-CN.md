# 谱系提示的两个 20 条窗口

基于 Core `fe172738ca0d88f3ffc61c447bcf4ddaab5332b0`、Pro `89889e6893aaeeed80d6f24fb1a6b5b5c30bab18`。谱系策略只显示 20 个满额父节点和 20 个近期可选父节点，旧版为两份完整候选集合分别排序。现在普通字符串 ID 使用有界堆选取这两个窗口；特殊类型 ID 沿用原排序路径，保留原异常。

## 行为和范围

满额列表仍按子节点数降序、ID 升序排列；可选列表仍按创建时间、ID 降序排列，并保留同键稳定顺序及重复数据库 ID。窗口之外的父节点仍参与完整谱系过滤。原 SQL、整表 fetchall、七日截止时间的计算位置、完整 scored 集合、全部子节点计数、错误处理和实际过滤函数均未改变。

这只减少两处排序的临时保留。完整数据库行、scored 集合、子节点计数以及过滤阶段的计数副本仍随历史增长；单个字段没有新字节限制。没有引入跨阶段快照保证，也没有为完整研究或 RSS 建立硬上限。

## 基线和差异检查

既有 96 项通过、13.35 秒。新增 17 项检查覆盖窗口边界、同时间 ID 次序、重复 ID、特殊类型异常，以及提示窗口外满额父节点被拒绝、未展示旧父节点仍可使用。固定 20,000 条短字段的真实 SQLite 策略加载在独立解释器中测得旧峰值 8,809,894 bytes，超过该夹具的 8 MiB 阈值。

首轮为 15 通过／2 失败：一项为上述成本失败，另一项为测试将原错误文字 `fan-out` 写成 `fanout`。只修正文案后，旧版 16 通过／1 成本失败；两次各 0.81 秒，均保留。实现后最终定向 113 通过、13.98 秒。阈值仅适用于这份固定夹具。

正式差异检查共 45 组：40 组完整策略、实际 build_prompt 原文及过滤结果相同；5 组保留旧特殊字段或参数异常。覆盖 0／1／19／20／21／100／1,000／20,000 条、多个上限、重复 ID、损坏／缺失数据库和时间字段边界。原型原件及其提交字节绑定单独归档。

## 实际 HTTP、CPU 与反事实

两个独立默认研究项目均导入 260 条合格报告。普通项目另有 31 个父节点各 12 条近期失败子节点，共 372 条；反事实再为最新可选父节点增加 12 条，共 384 条。完整观察器核对 260 个 scored ID 和 31／32 个计数项，提示只显示各 20 条。

真实 research CLI 通过 custom HTTP backend 调用 loopback 确定性 provider。provider 只从实际提示解析可选列表、满额列表及当前合格基线，没有接收预定父节点。增加子节点后，首个可选父节点及实际提案、CPU 产物从 `idea-history-0259` 变成 `idea-history-0258`。第 31 个满额父节点不在提示窗口内，但仍保留完整计数；窗口之外的过滤行为另外由定向测试验证。

两次实际 CPU 动作、八次新进程 CLI、两次 HTTP 请求通过正常决策、源锁与准入；TREE_CLOSED／ECHILD_WALL、结算、执行引用、产物 SHA、prompt manifest 和四张表精确重放均核对。导入历史及确定性 provider 不代表真实模型或科研收益；许可证替身仅存在于隔离 Pro 子进程，原 Core-only 可选扩展诊断保留。

## 回归、失败与封存

Pro 首次全量命令漏写 `tests` 参数，误收集证据目录中的历史测试副本，产生 56 个收集错误，退出码 2；没有将它计为通过。保留原运行后以独立 basetemp 和明确 tests 目录重跑，源码未变。

Core 一次全量 5,046 通过、7 可选跳过、2 既有 warning，1084.71 秒；Pro 修正收集范围后 1,280 通过、329.17 秒；配对 31 通过、0.67 秒。集合重叠，不能相加。完成运行的源码／测试输入冻结，9 份归档含 1,446 个文件，压缩件、全部成员 SHA 与原目录字节一致。预核验 SHA-256：`18f4d4e2bdc9590ce8bca64d6dc7c4098988bd16886bdf0560c9a4d91e0fc274`；最终 verification.json SHA-256：`5ee8758de47c9c959c078c14f3c46b8a7f492571aff7e6c897e7d4dbe7086ca4`。独立进程机械核验不是另一位审阅者。
