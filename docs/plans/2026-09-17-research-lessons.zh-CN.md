目标是更快、更省地得到可靠的研究结论。实现功能和降低局部开销有价值，但都需要回到这个目标验证。
依据是[研究进展评估](2026-09-16-research-progress-assessment.zh-CN.md)和

## 已有证据教会了什么

| 观察 | 后续做法 |
| --- | --- |
| CPU 收集器已有正确评价，模型却只看到 `local_metrics_missing` | 检查实际发给模型的提示词、实际响应和下一步动作。产物存在不等于信息被使用。 |
| Haiku 已跨轮读回记忆，却重复写同一反例，两个研究轮次没有新提案 | 记忆应帮助下一次决定。优先复用，只为新证据或有用的新假设写入；不要把笔记数作为产出指标。 |
| 写入额度用完后，提示词仍展示完整写入模板 | 根据当前状态只展示可用动作。先消除已观察到的无效选择，再考虑增加能力。 |
| 第一版隐藏了模板，末尾却仍提醒先写笔记；四对中有效改进反而由 2/4 变成 1/4 | 检查模型实际收到的完整提示词。局部文案正确仍可能被另一处指令抵消；修改必须经过真实对照。 |
| 第二版消除了本组的协议失败，却仍有更多无效候选和耗时退化 | 流程畅通和科学有效要分别计数。不能把更顺利地产生错误候选算作研究能力提升。 |
| 仅强调裸 JSON 仍失败，完整代码块兼容后才实际写入成功 | 在真实模型边界验证协议；可无歧义归一化的包装应简化，内容、来源和预算校验继续严格。 |
| 一条有来源的说明把冲突时间写错；`current` 只代表出处有效 | 分开记录来源资格、自然语言真伪、候选合法性和独立确认的质量。引用不能替代内容核验。 |
| 记忆开／关短任务结果不同，但所有正式项目都没有写入记忆 | 先验证机制是否发生，再解释效果。可选接口的差异不能归因于记忆复用。 |
| sidecar 等局部扫描明显加速，完整 CPU 对照却没有稳定整体提速 | 同时报完整时间、模型调用和本地工作；不同条件的局部倍数不能相乘。 |
| 更强模型两次输出截断；无效提案和重复提案也消耗费用 | 保留固定样本、所有失败与未知费用。比较相同质量所需的完整成本，不能把更快失败称作提效。 |
| 新任务删除强制记笔记规则后更快、更便宜，但质量更低，且两组都没有实际写入 | 质量不同就不能宣称等质量提效；没有发生的机制不能用来解释差异。 |
| 放宽输出额度后 Sonnet 在一道新题得到可证明的最优解，另一题却连续超时 | 模型能力、输出额度、推理强度和请求超时一起影响可用结果。开放显式配置，按任务校准，不盲目扩展全局默认。 |
| medium 固定两轮从约 240 秒降至 201 秒，首次最优却从约 113 秒延后至 199 秒 | 同时报告首次达到共同质量目标与完整预算内结果；固定轮次更快不等于更快得到好结论。 |
| 多轮工程增加了可核验能力，但没有证明长程研究收益 | 每次改动绑定一个真实损耗和一个研究指标。没有测得收益时，停止扩展该方向，回到实验。 |

## 接下来的工作规则

1. **先提出研究问题。** 写清触发条件、预计减少的浪费、质量约束和失败判据；冻结对照、顺序和预算后再调用模型。
2. **做最小的有效修改。** 优先删除无用选择、重复内容和矛盾规则。只有实际瓶颈需要时才引入新基础设施。
3. **完整计算一次研究的成本。** 从输入准备到独立评价，计入失败、重试、记忆操作和本地时间；另外记录首次有效改进时间。
4. **以结果选择下一步。** 有效改进数、确认质量、等质量时间／费用和重复失败是主指标；测试数、笔记数和提交数不是研究收益。
5. **区分探索和验证。** 小任务机制诊断可以指导修复；更难任务、长历史和跨领域对照决定通用结论。不要不断在同一道小题上调提示词，再称之为泛化。
6. **保留必要的可信边界。** 来源变更、预算、所有权和恢复语义不能靠猜测跳过。先定位开销，再删除重复工作。

## 本次可检验的简化

提示词修改处理已经观察到的重复记忆写入：有额度时说明复用和可选写入；额度耗尽后移除写入模板；默认示例使用空 `refresh`，明确必填字段。
存储、来源、预算和拒绝路径保持原有实现。

预先固定四对真实模型流程诊断，顺序 AB／BA／AB／BA，每项目两轮、相同请求和 token 额度。
双方从实际 CPU 评价过的 14 分有效种子和容量冲突反例开始，不提供已知最优排程。
A 使用冻结的旧记忆提示词，B 使用本次简化；双方均提供记忆，并使用相同任务要求。
主指标是是否产生经独立复验、严格优于种子的有效新候选，同时计入全部调用、时间、费用和失败。
这项实验检验流程简化，不证明“记忆优于无记忆”，也不替代长程研究验收。

第一阶段四对已完成：只隐藏模板没有提效。保留全部负面结果后，第二阶段再固定四对，
比较是否统一末尾的可用响应选择：写入后停止并等下一次提示；额度耗尽时只列出提案和证据读取。
研究要求、种子、模型及预算继续相同。第二阶段是根据第一阶段观察作出的探索，不能当作独立盲测。

随后在两道新的九作业任务中，固定两对“先写笔记／记忆可选”的研究流程对照，使用相同代码、模型和预算。
一个任务容量为 1，另一个容量为 2，均从实际评价过的次优种子和反例开始。这个问题直接检验删除强制记录步骤的价值，
不再为同一道题继续增加提示规则；它仍是小规模同领域探索。

两道新任务又分别完成 Sonnet high 和 medium 的固定两轮实验。保留全部 5 次超时后，
证据只支持一道题的解质量提高，尚不支持通用提速或 medium 默认更好。正常研究入口新增两个可选设置，
使后续校准无需替换模型调用函数；缺省行为及共享预算保留。这是针对实际截断和超时的最小修改。
