# 标题缓存对象的存活期与实际研究消费者

## 改变了什么

三个既有排名消费者仍在原来的时点读取同一个有界标题缓存，但现在只让必要的 ID→标题映射跨过完整资格扫描。共享私有函数返回后，完整解码对象及其无关字段不再被调用者局部变量保留。缓存仍只提供显示标题，不能提供分数、资格、来源或排序权威。

基线 Core `01d8455b5277d8139296449432af7d568b120447`、Pro `8ef545a8cf7f5032cee1e655e6959002531d64af`。Core 产品代码未改变；Pro 仅提取标题读取代码，新增 33 项兼容性用例。机械核验将调用点内联回原来的三条语句后，三个消费者 AST 与旧版相同；其他函数 AST 和所有已有源码／测试 Git blob 保持一致。

原 2 MiB 读取限制、最后重复 ID 覆盖、字符串化及 200 字符截断、无效缓存回退、扫描中改动下一次调用生效均保留。没有跨调用缓存，没有减少资格读取，也没有将标题来源升级为合格证据。完整解码的瞬时成本、必要标题映射及其他上游输入仍存在，文件限制不能代表整个研究调用的内存上限。

## 行为与真实 CPU

旧版基线和候选版各 140 项通过，含 33 项新兼容性用例；这是行为保持验证，没有人为制造旧版业务失败。精确大小边界、损坏 JSON／编码、非列表、复杂标题、重复 ID、扫描中缓存变化，以及当前报告缺失均有实际输入覆盖。

- Core：5171 passed, 7 skipped, 2 warnings in 1133.77s (0:18:53)。
- Pro：1529 passed in 439.10s (0:07:19)。
- 配对：31 passed in 0.76s。

集合存在重叠，不能相加。每次测试使用唯一 basetemp，记录器确认源码和测试在运行前后相同，进程完全结束后才修改输入。

两个隔离项目各执行一个 CPU 源报告和一个后续 CPU 提案，共四个 worker、六次 Core CLI、四个新研究消费者。源产物的原字节经显式导入成为当前指标；缓存包含 4,000 个没有证据的虚构 ID、重复源 ID、约 1 MB 无关字段，以及伪造的 -999 分数。消费者实际看到不同显示标题，但仍使用真实报告的 -3 指标，后续 CPU 产物写出实际收到的标题和指标。

每个项目还先移走当前指标文件：同一个缓存不能恢复合格排名，消费者返回空批次。恢复原产物后，由新的调用重新核验资格；这不表示旧身份绑定被复活。原生 `TREE_CLOSED`／`ECHILD_WALL`、SETTLED、产物 producer／SHA 和重放没有重复写入均经核对。缓存仅在消费者调用前后保证字节不变，后续正常 Core 报告可以更新它。

许可检查仅在隔离 Pro 进程使用替身。离线 provider 验证真实消费和执行链，没有外部模型、账户、GPU 或现有服务调用，也不代表科研质量验收。

## 保留的成本脚本问题

最初 probe-v1 和 benchmark-v1 使用恢复整个 `sys.modules` 的测试工具。诊断发现，真实消费者中新导入的 14 个依赖在退出调用后全部被删除，造成重复导入与额外分配；这些原始记录保留，但不作为最终成本验收。

新脚本只切换目标 evidence 模块及包属性，并只恢复这两个位置。独立新进程诊断确认 14 个依赖全部保留，新旧切换方式的完整提示词和结果逐字相同。每个测量域均核对实际资格函数调用次数、源文件身份、完整输出及提示词清单，避免新旧两域误用同一实现。以下最终成本均来自修正脚本。

## 核验与未关闭工作

18 份归档、154,502 个普通文件、116 个链接、0 个 FIFO 类型条目，原件、归档字节及链接／硬链接身份逐项核验。预核验 `47600501480287a5975fde5cde517b39aacf2389bf140f858d8b30ed4b23a0d3`；最终 verification.json SHA-256 `5c4e6c7c419c85c9d16039e32893d1f78be0609c7e6f239ea9df5759d56bb5cf`。机械审计由独立 Python 进程执行，仍由同一代理发起，不等于独立人工审查。 源码／CPU／模块表的轻量组件预核验与第二轮内存采样有时间重叠，组件核验本身不提供性能结果；最终全量测试、归档及完整核验均在全部成本采样结束后启动。

公开 Core 仅保存自己的回归、说明和[私有证据索引](../evidence/2026-09-16-title-hints-lifetime-pro-private-index.json)。早期有重复导入的两次成本与最终结果分开保留；修正版 benchmark-v2／v3、memory-v1／v2 及八个缓存形态对照为最终测量。

完整资格扫描、ID 结果列表／作者源、谱系 rows／sets／counts、家族统计及其他消费者仍待治理。持久记忆语义压缩、真实多轮研究、CephFS／生产兼容、隔离／备份／回滚、真实许可／模型与受控上线、P3 跨领域等质量验收仍开放。本片完成不代表整个目标完成。
