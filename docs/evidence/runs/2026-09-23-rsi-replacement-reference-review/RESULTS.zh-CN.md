- CLINC150、Gas Turbine NOX 各两实例：8 次共同参考训练成功，4 个参考只按开发损失选择，12 次独立重载预测完成。确认/审计只生成预测，没有读取其标签评分。

- 独立生成 CVRP100 的 32 个校准实例，两份参考与首轮见证完成保存/重载。首轮见证相对逐实例较好参考差 4.9653%，校准失败，全部保留。
- 后续只在该校准池，将同一个 OR-Tools 求解器改为从两参考中较好路线及其最优容量分段开始搜索。参考、分布、2% 改善、配对区间及 300 秒门槛不变。接口依据 [OR-Tools 官方初始路线说明](https://developers.google.com/optimization/routing/routing_tasks)。见证不会插入模型研究对照。
- 新见证均值 13.338728，逐实例较好参考 13.495846，改善 1.1642%；配对分组 bootstrap 差值 97.5% 上界 -0.102582。包含初始化的 worker 时间为 254.38 / 253.94 秒，独立重载完全一致。**可达性校准未通过**，不意味着研究模型能发现该方法。
- 新见证部分实例达到8秒安全时间附近，两次搜索的solution计数不同但最终预测相同；这证明本次重载一致，不证明任意机器负载下路径确定。
- 本轮共 28 个 CPU worker 闭合；首轮 18 份开发预测与后续两份见证由独立数值实现重新评分。CVRP 使用另写的后向最短路径分段计算，没有执行候选源码或读取 pickle。
