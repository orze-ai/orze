# 按实测耗时分配研究计算：开发对照

这是两个已观察过的开发任务 Fashion-MNIST / 电厂回归，各 control/effort 一次，共四次研究。结果不能用于声称通用能力、30% 泛化收益或升级默认。

两组都使用相同 ParallelRefine、Opus 5 high / 32768 输出上限、两路径各两步、两请求并行准备、单任务串行实验、同一数据和参考模型。control 是当前默认研究提示；effort 仅增加已闭合参考/本分支实验的实测墙钟信息及据此选择实验规模、停止条件和兼容模型复用的指导。它是组合干预，不能把收益单独归因到提示或反馈。两组均沿用原 build/train/predict/analyze 接口与父模型权限，不启用 pilot 或 inquiry 共享证据。

不规定训练秒数、算法、低成本优先级或必须复用的比例。较昂贵的全新表示/算法若可能更快达标仍应探索。只把真实训练/分析容器的闭合记录和 worker timer 抄入 recorded_execution；不把确认/最终分数、标签、时长或新执行中的信息注入研究提示。worker 时间缺失标为 unknown；不能伪造成零。容器时间含加载、计算、存储和开发预测，不叫 GPU 利用率或纯训练时间。

每次至多四提案、7200 秒；开发目标后最多一份 fresh confirmation 和一份最终 audit。最终通过须同时满足 10% loss reduction 与 paired-group bootstrap 97.5% upper difference < 0，迟于期限或失败记 7200 秒。交付事件与请求结算分开保留。无自动重试、无人工候选注入。

GPU 0/1 为 Fashion、2/3 为电厂，已冻结跨领域任务仍用 6/7。共享机器/提供方拥塞均计入实测时间。模型及算力条件保持对称，但这种两任务开发结果不提供稳定的通用时间效应估计。

总保守池 $12.50，每次 $3.125，来自已验证释放后的 $12.5928 未分配授权；累计保守分配 $4999.9072，不超过 $5000。旧跨领域 $160 池与 25 条历史未知请求均不释放。这个开发池小于上轮 pilot 的 $18，组内对照有效，不能直接比较两轮均值来归因。

检验：11 项离线控制器测试通过；输入/方案在首次请求前冻结。结束后独立重算所有开发与最终预测、逐个核对提示证据、请求/容器闭合及费用。两任务均无成功率退步且配对均值更低才考虑进入新任务验证；开发成功也绝不直接改默认。失败和未使用提案全保留。没有新增定期监控。

论文启发遵循 RRSI 的小改动及负结果保留、SoL-Pi 的减少重复中间工作、RSIAgent 的针对知识缺口选择实验；它们没有证明本候选有效。最终跨领域验证仍须使用机制冻结后的新任务与修复的随机行序切分。
