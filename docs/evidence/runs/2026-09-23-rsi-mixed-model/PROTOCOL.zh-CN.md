# 固定资源的研究模型互补：开发对照

这是已经观察任务上的开发筛选，不是新的前瞻能力证明。源码排序诊断已完整闭合、核验、结算；其失败配置不重试，也不加入本对照。

## 唯一干预

control 两条研究分支都使用 `claude-opus-5`。candidate 在 repetition 0 使用 b0=`claude-opus-5`、b1=`claude-opus-5-5`，repetition 1 交换绑定；整条分支的三个深度保持同一模型。模型身份只由冻结的 repetition/branch 映射决定，不根据任务、候选结果、响应速度或审计结果改选。

两组均沿用原 `run_prepared` 和 ParallelRefine：两分支、各三步、最多六次请求、两并发准备、按完成顺序串行执行。相同提示和原有本分支历史，没有额外跨分支快照、inquiry、源码评审、延迟确认或人工候选。high effort、32768 输出上限、无自动重试和后备模型。更换模型可能改变到达顺序，这是本干预的实际影响，计入时间。

## 固定任务、输入与资源

KMNIST、Abalone、TREC、生成 TSP-320，各两次重复、两组，共 16 次。前三个来自公开真实数据集；TSP 是生成优化问题。数据、共同参考和检查点逐字节复用已结束的确认选择开发试验，不重训或改选参考，不把旧任务包装成未见任务，不向模型提供历史候选源码或最终验收结果。

四条固定任务通道分别分配 GPU 0/1、2/3、4/5、6/7；每通道同 repetition 同时开始两组，第二 repetition 交换组与 GPU 对应。每研究实例只使用一块 GPU，各容器 2 CPU、12 GiB 内存、约 6 GiB PyTorch 显存，固定镜像、离线只读隔离。真实数据任务训练/分析 900 秒、预测 600 秒；生成优化均 1800 秒。原始模型执行自行消耗的预算、编译时间和失败都计入研究时间，不额外并行两条完整研究轨迹再取较优结果。

每实例截止 7200 秒、最多六次请求、API 池 $10；全轮池 $160，累积不得超过用户授权 $5000。仅在启动前根据最新源码排序结算账本分配，历史 25 条未知费用完整保留。请求准入使用原保守 token 包络和模型费率，所有未准入、截断、失败及付费未使用提案保留。未准入没有发送付费请求；未知用量不释放预留。

## 外部验收与主指标

两边完全相同：首次严格开发提升且达到固定幅度时用一次确认；确认通过后执行一次独立审计，确认失败继续探索。预算末只审计开发集选出的最佳改进方法一次，不看审计结果换选或重试。候选容器的确认/审计预测只获得特征；隐藏标签由宿主独立评分，不执行候选自报指标。

主指标是每研究实例开始至最终验收交付的墙钟时间，包括模型等待、代码失败、训练/分析、确认和审计。未通过或交付超过截止时间统一计 7200 秒。四任务类等权，不仅平均成功者。`goal-delivered.json` 可以早于仍在途请求结算，`completed.json` 记录全部已发请求结算后的状态。

开发晋级必须同时满足：全部 16 次闭合且独立核验有效、所有请求用量已知、平均达标时间至少降低 30%、至少三个任务类更快、每任务类成功数不下降。报告四类配对 95% t 区间、符号翻转统计和所有失败，但本开发筛选不能通过任何数值直接升级默认或完成目标。晋级后仍须新的四领域前瞻对照通过原不确定性门槛，并完成实际入口绑定和平台默认验证。

control 是此前前瞻试验的明确模型比较对象，不自动代表项目 `backend: custom / model: sonnet` 的实际运行绑定；不得只改通用模型回退值宣称平台升级。

## 依据与边界

完整旧配对显示两模型有不同的较快案例，但事后取两条完整轨迹的最优使用了额外资源和最终验收信息，不能估计本混合分支的未来收益。[RSIAgent §3](https://arxiv.org/html/2609.15364v1) 启发互补探索与环境反馈核验；作者没有证明本模型组合。[Dream-RSI](https://arxiv.org/html/2609.14858v1) 提醒回放只覆盖已观察节点，改变模型必须在线测量。[RRSI](https://arxiv.org/html/2609.24972v1) 的可归因小改动和负证据原则在这里体现为只改变一条分支的模型，不扩建评审框架。

只有离线协议检查通过、全部输入/代码/资源/费用冻结且 `plan.json` 为 frozen，入口才可请求模型。一次性实验所有者负责闭合后核验，不创建新的定期监控、不改服务、不停止其他 GPU 作业。结果无论正负都归档并提交到两仓 main。
