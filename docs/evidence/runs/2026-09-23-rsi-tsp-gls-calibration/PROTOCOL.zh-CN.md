# 固定 GLS 求解器的独立 TSP 可达性校准

原校准的 160 点 TSP 在既定 400 秒整批预算下仅改善 1.89% / 1.97%，未达到 2.5% 校准门槛。数学下界允许的改善上限为 3.34% / 3.56%，尚未排除门槛，但也没有证明可达。原方案、所有失败和选择结果不改写。

本次只检验更强固定求解器是否能提供可达见证，0 次研究模型请求，不是自主研究或研究效率对照。采用 [Voudouris 与 Tsang 的 GLS 原文](https://bracil.net/CSP/papers/VouTsa-GlsTsP-Ejor99.pdf) 中的边效用惩罚思路，NumPy 实现完全 2-opt 邻域，alpha 固定 0.3；不安装外部求解器。不声称这是新的 RSI 方法。已在独立 4–8 节点小图上检查移动差值、输出排列和真实路径计分，没有使用校准或未来测试输入调参。

保持已经提出的 160 点均匀/聚簇各半分布，重新生成两批各 64 个实例；不得复用原校准实例或未来效能实例。原两个参考源码、检查点、重启次数及迭代强度不变。以两个参考逐实例更优结果为基准；两批均达到 2.5% 平均改善和配对 bootstrap 差值 97.5% 上界为负才合格。未来效能目标仍为 2%，不因本结果改变。

每批固定三个方法，GPU 6/7，各自串行。原参考最多 1800 秒，GLS 整批内部 400 秒、容器最多 600 秒；与原见证相同实例数和预算。相同离线、只读输入、2 CPU / 12 GiB 限制，不停止其他服务。GLS 使用只有预算和固定 alpha 的配置，不训练模型、不读取标签，也不复用已算出的路线。

全部六次执行闭合后由独立校验器重算排列长度、检查数据互斥、冻结哈希及选择条件。若失败就保留失败，不反复在同一批调参并宣布独立通过。即使合格，也只证明这些独立校准实例上有见证；未来研究任务必须重新生成并在双方请求前冻结。不得把本次人工求解能力加到研究模型的成功率或 30% 收益中。
