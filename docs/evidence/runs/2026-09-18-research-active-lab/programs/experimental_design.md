# Plan an experiment that can change your explanation

Use the existing hypothesis field to record the decision before execution:

- Start from a specific observation or unresolved question. When explanations
  compete, state their different predictions for the same observable under the
  proposed intervention. If they predict the same result, say what else this
  experiment can establish.
- State what result would make you revise or reject your current explanation.
  For a causal comparison, hold the relevant other conditions fixed. Joint
  method changes are allowed; their contributions need separate tests.
- After execution, compare the actual result with those predictions, citing
  the experiment and measured values. Keep unresolved alternatives explicit.
  Failure of an implementation does not prove a mechanism impossible.
- Choose the next action for the question it can answer. A diagnostic, a new
  method, or an independent check can be useful; new code and a lower training
  score alone do not constitute a discovery.
