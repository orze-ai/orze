# 八任务的参考准备完成；研究效率目标仍未验证

六个公开数据集、最大割和作业调度两个生成优化问题类，各两个重复，共16个研究实例的输入和共同参考已经准备完成。参考只按开发结果选取；本轮没有研究模型请求、没有最终研究验收，不改变产品默认。

优化参考的“准备”包含算法初始化和开发预测，不是学习模型的参数训练。两套参考都必须成功，不能从失败后的幸存者中选取参考。独立核验重算开发结果、检查重载一致性、输入/源码哈希、确认/审计的特征挂载和所有容器闭合。只保存确认和审计预测，没有利用其目标值改方法或选择参考。

作业调度选中的开发平均完工时间为1521.84375、1543.4375；最大割选中的开发平均未切边权重为11275.90625、11307.875。这些是共同起点，不是研究成功。

## 最大割：保留失败，先修正评测准备

前一轮较密512点图的两种离散搜索见证未通过2%要求。本轮另外实现了受[Burer–Monteiro–Zhang秩二松弛](https://sburer.github.io/papers/005-rank2maxcut.pdf)启发的连续角度优化、划分取整和离散搜索组合。小图梯度、目标计算、重载确定性及穷举最优检查通过；32个原校准图上的真实改善为**1.9051%**，独立预测53.94秒，仍未通过。这不是原论文完整算法复现，也不提供大图最优性证书。

事后按实例取各见证较好解，两个方法的组合估计为1.9367%、三个方法为1.9385%，仍低于2%。没有再执行这个无法满足幅度要求的组合；其耗时相加只作为筛查估计，不包装成已测墙钟收益。

随后在任何新研究模型请求之前，另行校准标准稀疏随机正则图：512点、4度/6度各半、正整数边权1–100、连通图、私有顶点与行序。参考仍是原128起点局部搜索和带暖启动CP-SAT，阈值、资源与逐实例较优参考口径均保持不变。没有删除最大割类别或降低参考来通过原试验。

| 校准项 | 结果 |
|---|---:|
| 两参考逐实例较优的平均未切边权重 | 11131.5 |
| 固定16起点×16000步禁忌搜索见证 | 9063.28125 |
| 相对改善 | **18.5799%** |
| 配对分组差值97.5%上界 | −1926.8102 |
| 32实例独立预测 | **10.24秒** |
| 执行及重载 | 三方法有效，六容器闭合，预测完全一致 |

这是观察校准失败后的任务设计调整，不能视作前瞻研究能力成绩；较密图的失败和源码继续保留。稀疏正则图是已有组合优化研究使用的图类，[MaxCut-Bench](https://arxiv.org/html/2406.11897v1)也讨论了图分布和强传统参考对结论的影响；本轮参数是自己的明确设计，不声称复现该论文的数据分布。

## 新输入与可推广范围

校准通过后才生成384个新的最大割实例，覆盖两重复的训练64、开发32、确认32、审计64。独立核验确认：每份4/6度各半、对称整数邻接矩阵、无自环、连通；八个划分互不重叠，与此前480个不同输入/校准实例也无重复。生成种子和原始图不入仓。新实例没有用于选择见证算法；共同参考预检完整结束。

“18.58%”只证明这套校准分布有可执行的改善空间，不保证研究模型发现该方法，也不保证每个未来审计划分达标。见证算法不会作为人工候选插入研究对照。四领域仍是最终不确定性单位，不把16个实例或32次对照当作32个独立领域。

## 当前还缺什么

1. 在可独占设备上完整验证真实原生控制器。此前原生入口因既有GPU计算进程被拒绝；没有取消检查或改动现有服务。
2. 将待测机制绑定到同一原生研究入口，明确与实际Sonnet默认流程的差别，再冻结两组。旧Opus5/5.5混合分支开发筛选不能替代这一步。
3. 运行并独立核验完整32次前瞻研究，满足原定至少30%平均验收达标时间下降、领域配对区间、至少三领域更快及成功率要求。

原生入口资源问题已向用户询问，等待可用独占GPU或节点信息。费用账本未新增：保守累计4627.321975美元、未分配372.678025美元。所有准备和校准耗时都是开发成本，不计作研究效率提升。
