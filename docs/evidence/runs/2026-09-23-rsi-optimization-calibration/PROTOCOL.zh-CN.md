# 优化目标独立校准：在研究候选运行前确认改善空间

旧试验中两个 TSP 开发集的 2% 门槛不可达。因此新试验开始前，先用独立生成的校准实例检查是否存在有效改善见证。这里的固定求解器来自已结束的旧试验，不是新自主研究候选；结果不计入研究能力、成功率或 30% 效率目标。

预先冻结四个完整分布：原 80 点 TSP 与 160 点 TSP（均匀/聚簇各半）；原 32 设施稠密 QAP，以及 64 设施稀疏重尾流量、几何距离 QAP。全部属于生成优化问题，不能称为真实采集数据。每个分布两批独立随机实例，每批 64 个，共 512 个实例；校准实例不得进入未来效能试验。

每批运行原来的两个参考和一个旧见证求解器，共 24 次容器执行。参考源码、重启数、迭代数和保存模型保持不变；参考容器最多 1800 秒，见证容器最多 600 秒。TSP 见证保持整批 400 秒，QAP 保持整批 300 秒、2048 条搜索链，因而每批的实例数与原最终审计相同，不借小批次悄悄增加每实例预算。八个批次使用 GPU 0–7，每个 GPU 内串行执行三个方法，受原 CPU/RAM/显存限制约束。

校准使用两个参考的逐实例更优解作为更严格的比较基准。一个分布只有在**两批均**达到至少 2.5% 均值改善、配对 bootstrap 的差值 97.5% 上界小于零，且输出排列有效时才合格。未来效能目标仍为 2%；校准的 0.5 个百分点是事先固定的余量。默认先选原规格；原规格不合格且预先定义的替代规格合格时才选替代；均不合格则保留失败，暂不启动完整效能比较。所有规格的结果一并保存，不挑选个别有利实例。

合格仅表示有限校准样本上有实际有效解，不保证任何未来随机批次都可达。新规格若获选，未来任务定义必须在双方研究请求前共同冻结，重新生成全部优化输入并预检参考。不能把规格变化解释为算法收益，不能事后删除优化领域来满足 30% 指标。独立校验器将重算所有排列目标、预算闭合、哈希以及上述确定性选择规则。
