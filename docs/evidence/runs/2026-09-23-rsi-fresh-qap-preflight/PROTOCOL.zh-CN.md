# 新 QAP 共同参考预检

此前独立校准按预注册规则选择 64 设施稀疏重尾 QAP。本次重新生成两次划分，每次训练/开发/确认/最终为 64/32/32/64 个实例，独立私有随机种子，与全部原校准及先前准备的优化输入互斥。全部为生成实例，不是真实采集数据。研究模型尚未接触这些新实例。

两份原参考代码不变，重启次数和迭代强度不变；每世界只按两份完整开发预测的目标函数选择共同参考。随后从同一已保存模型独立重载开发、确认和最终预测；开发排列必须精确复现。确认/最终成绩不用于改阈值、选择参考或挑实例。

两世界分别在 GPU 3/4 串行运行各自五次容器，共四次训练和六次重载预测，不使用正在进行模型对照的 GPU 0/1/2 或 TSP 校准的 GPU 6/7。相同离线隔离、2 CPU、12 GiB、约 6 GiB 显存限制，其他服务不动。

鉴于原较强参考整批预测实测 1517/1597 秒，本次训练/分析及独立整批预测统一上限 1800 秒。下一轮双方优化任务都必须使用同样上限，且全部计入原 7200 秒研究交付期限；真实数据任务保持原 900/600 秒。不能让较强参考在旧 600 秒上限下超时后静默弃用，也不允许给候选免费计算。

预检在完整源码、生成规则、种子、数据、资源与选择规则冻结后执行；独立验证将重算所有排列目标、核对实例互斥和容器闭合。任何失败保留，无自动重试或基线削弱。0 次模型请求，基线预检不计入自主研究最终验收或 30% 效率收益；TSP 校准或模型筛选尚未完成不妨碍这一独立共同起点准备。
