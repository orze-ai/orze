# 新任务模型对照：均值降低 33.15%，未满足默认升级条件

32/32 完整结束，最终验收共 24/32；106 次请求均已知用量并结算。相同 ParallelRefine、资源、提示和执行方式，仅将研究模型由 Opus 5 换为 Opus 5.5。六个公开真实数据集，另有 TSP-320 和稀疏重尾 QAP-64 两个生成优化问题类，各两次重复。

时间为每次研究启动到最终验收交付的墙钟时间，包含模型等待、无效尝试、执行、确认和评分。未达标统一计 120 分钟，基线预检和仅开发提升不算验收成功；交付与请求结算分别留档。

描述性均值下降 **33.1486%**。candidate 减 control 的领域配对 95% t 区间为 **[-61.3843, 25.1715] 分钟**，包含退步，符号翻转双侧 p=0.50。只有文本、生成优化 **2/4** 领域更快；视觉和回归更慢。未观察到领域成功率下降不是强统计非劣证明。

**决定：不升级产品默认，30% 平台目标未完成。** 点估计超过 30% 不等于通过预先固定的完整门槛；四领域是四个不确定性单位，不能把 32 次研究当成 32 个独立领域。

## 任务差异与方法证据

- 文本收益集中于 TREC；AG News 两边均失败。TREC 候选使用实测的特征/分类器拓展，但 control 也曾尝试并因内部表现弃用 CNN，不能把失败简单归因于缺乏探索。
- TSP 两次均通过，任务均值下降 60.42%；QAP 两次均通过，下降 34.56%。生成优化领域合计下降 50.85%。双方都使用常规局部搜索/禁忌搜索；预算、并行方式与搜索细节同时不同，不能当作单因素消融或通用创造力证明。
- 新增 QAP 第二次双方六份开发/确认/审计排列及参考目标的独立双重求和重算一致。候选的编译/计时探针实际使用第一条开发特征，并非独立训练质量评估；control 的自报均值使用不同数量的训练实例，不能直接相比。完整方法限制见 `qap-complete-review-001.json`。
- 保持既有轨迹的方法/结果，仅去掉全部非执行时间仍不能逆转视觉、回归领域的退步；没有证据支持仅重写异步调度就能满足当前目标。后续优先验证确认与探索的选择时机。

## 下一步与平台绑定

已启动四个已观察任务 KMNIST / Abalone / TREC / TSP-320 的 16 次开发对照。两组都用 Opus 5.5，唯一干预为立即确认或首批两方法都测完后选优确认；保留确认失败后的后续探索，并计入新增执行时间。原始输入、参考、245 个文件及两组首批提示已核对冻结。开发通过也只能支持下一轮新任务验证，不能升级默认。

真正的平台结论还缺实际运行入口绑定：当前工作项目原生 custom/sonnet 路径并未调用被测的 `run_prepared`。本模型试验只支持显式模型对照的范围；将来须把胜出组合落实到核实过现有方案的真实入口并验证，不以改通用模型回退值代替平台提升。
