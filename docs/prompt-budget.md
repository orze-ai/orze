# 研究提示预算与来源清单（V1-04B）

本项限制实际交给 `call_llm` 的完整提示字符串，不是字符估算、token 预算、HTTP/SDK 请求体上限或科研质量证明。

## 声明与必需内容

`research_prompt: {max_bytes: 131072}` 默认允许 128 KiB UTF-8 字节。只接受 `max_bytes` 一个键；值须为非 bool 正整数，最大 2 MiB（2097152）。显式 null、错误类型、额外键和越界值在上下文构建及 provider 调用前失败，不能退回无限预算。Core 配置检查与 Pro 使用同一校验函数。

系统提示、固定省略说明、规则原文、已启用的机械决策/单模型/谱系约束及任务都是必需内容，不截断。它们连同标题、分隔符装不下时，返回 `error / prompt_required_content_oversize`，不调用 provider。

原生调度的非空 `rules_sha256` 仍要求规则存在、非空、UTF-8 有效且哈希完全一致。规则读取最多 cap+1 字节，超限不截断、不回退；核验后的字符串保持 CRLF 和 Unicode 原文，不重新读取。兼容边界仍保留：旧调用使用空 hash 且规则文件不存在时，规则是可选项；已存在的旧规则也有读取上限。

## 可选来源与有界读取

纳入优先级是当前证据摘要、生成的研究上下文、作者回顾笔记、按文件名排序的 knowledge。预算优先级决定纳入多少，不强制改变旧版呈现顺序。可选内容只能取 UTF-8 完整边界上的前缀；不会把单行头尾重复拼接。每个提示都有计入必需预算的固定说明：省略不是负面证据，残缺片段不是可执行指令。

显式回顾笔记和 knowledge 的新读取器每文件最多读取 64 KiB，一轮合计最多 1 MiB，实际读出的探测字节也计入。knowledge 允许 128 个目录项，至多观察第 129 项判断越界；越界时记录目录省略，不任意选择一个目录前缀。坏文件、循环符号链接和读取失败不会吞掉独立的好文件。回顾文件及自动摘要通过解析后的路径去重，正文内部标题不会被当作文件名。

若读取正好达到上限而没有观察到 EOF，完整文件哈希保守地为 null。实际读取范围和哈希仍被记录；UTF-8 不完整尾部不进入提示。这里的 1 MiB 约束属于新回顾/knowledge 输入读取，不是旧上下文生成器所有底层文件 I/O、内存或 tokenization 的总上限。生成的摘要和上下文作为生成文本来源记录，不冒充其每个底层文件的完整读取清单。

## 清单与实际发布边界

`build_prompt` 继续返回 str，可额外填充 `manifest_out`；cycle 提供 `prompt_manifest_out`。每次调用先清理旧详情。清单只含预算、最终 UTF-8 长度/哈希、必需规则哈希和最多 144 个来源记录，不含正文或原始 nonce。来源记录区分完整文件哈希、实际读字节范围/哈希、实际纳入范围/哈希、最终提示中正文的字节位置及省略原因。标题和分隔符由最终提示哈希覆盖。

原生路径在 provider 前通过捕获的 attempt/role/scope/nonce 身份发布 `<attempt_id>.prompt.json`，清单文件另有 256 KiB 上限。发布采用专用身份验证和不可覆盖收据机制；发布失败返回 `prompt_manifest_publish_failed`，不调用 provider。发布前后均重新核对最终提示字节数和哈希。dry-run 只构建/显示，不发布清单，也不调用 provider。

`prepared_for_provider` 只表示调用前准备阶段，不证明 provider 已接收、计费、完成或产生有效结果；后续结果仍由既有原生结果协议处理。没有真实 provider/GPU/holdout 调用或科研收益声明。

## 回归证据口径

旧单行回顾重复是旧公共行为回归；24 文件和跨项目旧测试是兼容/测量控制，不是旧总预算能力证明。新 packing/清单验收、目录边界草稿修复和必需规则读取 instrumentation 迁移分别记录，不把不存在的新 API 算成旧错误，也不删除旧业务断言。
