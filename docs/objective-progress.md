# 排序变化与局部指标改善

`new_best` 表示当前合格结果之间、按已声明 objective 可确认的严格局部改善，不表示统计显著性、独立复验或历史最高纪录。

- 主指标不同：遵循 `report.sort` 的最小化/最大化方向；零和负数正常参与比较。
- 主指标相同：只有显式声明的 secondary metric 在两边都是有限数值时，才可据它判断严格改善。
- stable ID 只保证排序确定；ID 变化不构成改善。secondary 缺失、布尔值、非有限数与已测得数值不可据此判为改善。
- 旧冠军已失格或不存在时，只重新选择合格结果，不发送 `new_best`，不把重新选择当作进步重置停滞计数。没有任何合格结果时撤销 champion 和派生停滞状态。
- 即使当前 tick 没有 finished 项，也重验当前候选与既有 champion；空批次不发送完成、停滞或周期报告通知。
- 显式 champion guard 仅作用于可比较的改善候选；相同分数换 ID 或替换失格结果不触发该异常策略。

边界：此切片比较的是同一读取周期里重新核实的结果。结果原位修订、历史回退、同 ID 的多个 observation、重复完成投递及跨重启的唯一观察计数仍需要 observation/attempt 版本机制；这里不以文件 mtime、内容变化或不同 ID 冒充独立研究证据。既有启动恢复仍按 `metrics.json` mtime 重建停滞计数，状态文件仍逐 host 保存；本项不承诺重启后或跨 host 计数一致。已有停滞计数只是操作性诊断，不能据它自动宣告某种研究路线达到科学极限。
